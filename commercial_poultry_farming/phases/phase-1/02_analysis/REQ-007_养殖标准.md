# REQ-007 养殖标准 — 需求分析摘要

> 本文档为 `REQ-007.yaml` 的可读摘要，字段以 YAML 为准。

## 概要

标准管理下的养殖标准库维护页。按「标准名称 + 适用品种（多选）+ 适用月份（多选）+ 启用/禁用」维护标准主记录；通过行内「目标明细」打开 0–42 日龄（固定 43 行）×17 列标准参数表（日龄只读，其余 16 维可编辑 number），支持弹窗内「Excel导入」三步向导（下载模板→上传→结果）与弹窗内「导出」当前标准目标明细。下游：养殖端首页（REQ-001）按品种+日龄取目标温度/目标湿度/湿热系数/风冷系数；饲养日志（REQ-005）与标准值对照关系需求未写死，记 open_questions。

## 范围

### 范围内（in_scope）

- 查询区：标准名称（模糊）、状态（启用/禁用）；查询 / 重置
- 列表：标准名称 / 适用品种 / 适用月份 / 状态 / 操作；分页
- 工具栏：新增目标（无列表导出）
- 行操作：目标明细、编辑、删除（删除二次确认）

- 目标明细弹窗：43×17 可编辑表 + 导出 / Excel导入 / 取消 / 保存明细
- 目标明细弹窗内「导出」→ 下载当前标准明细 Excel（文件名 `{标准名称}.xlsx`）
- Excel 导入向导（导入目标明细）：下载模板、字段说明、上传 .xlsx/.xls、导入结果

### 范围外（out_scope）

## 业务规则

- 主记录维度：标准名称 + 适用品种（多选标签）+ 适用月份（多选标签，1–12 月）+ 状态（启用/禁用）
- **品种×月份全库唯一**（不可交叉重叠）
- 明细主键：日龄整数 0–42，共 43 行；原型日龄列只读；标准名称文案与行数无关
- 明细 17 列；**累计* 为纯输入**（非自动累加）
- Excel 导入：校验日龄 0–42；仅日龄必填；页面与导入必填规则统一；允许 0/空
- 导出：目标明细弹窗内；**仅已保存内容**；文件名完整 `{标准名称}.xlsx`
- 禁用后不可新引用（历史引用不受影响）；删除不影响历史引用数据
- 删除二次确认；主记录与明细写路径分离

## 原型要点

### 页面壳

- 菜单：标准管理 → 养殖标准；列表标题「数据列表」
- 工具栏：仅 `新增目标`（无导出）
- 行操作：`目标明细`、`编辑`、`删除`
- 查询：标准名称、状态；查询 / 重置；分页

### 关键按钮语义

- **新增目标 / 编辑**：仅主记录四字段（取消/确定）
- **目标明细**：打开「目标明细 - {标准名称}」；导出 / Excel导入 / 取消 / 保存明细
- **导出**：目标明细弹窗内；下载当前标准明细 Excel（非列表主记录）
- **Excel导入**：打开三步向导「导入目标明细」（下载模板→上传→结果）
- **删除**：MessageBox 二次确认

### 嵌套弹窗 / 子表

- 新增目标、编辑目标、目标明细、导入目标明细、删除确认（均已原型捕获）
- 子表「目标明细表」parent=`目标明细弹窗`；日龄只读，其余 16 维可编；固定 43 行
- 目标明细 `export_spec`：文件名 `{标准名称}.xlsx`；sheet `目标明细`；17 列×43 行

### 需求 vs 原型差异（摘要）


| 项        | 需求            | 原型                      |
| -------- | ------------- | ----------------------- |
| 编辑       | 改基本信息与明细      | 编辑仅主字段；明细走「目标明细」        |
| 新增       | 创建 0–42 标准数据  | 新增仅主记录；明细骨架在目标明细预置      |
| 按钮文案     | 「新增」          | 「新增目标」                  |
| Excel 导入 | 下载模板+范围校验     | 独立三步向导 + 字段必填说明表        |
| 导出       | 导出当前标准为 Excel | 入口在目标明细弹窗（非列表工具栏）；导出明细表 |
