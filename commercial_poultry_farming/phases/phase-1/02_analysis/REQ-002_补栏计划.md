# REQ-002 补栏计划 — 需求分析摘要

> 本文档为 `REQ-002.yaml` 的可读摘要，字段以 YAML 为准。

## 概要

展示由产业链生产排程系统下推生成的补栏（上苗）计划。按年份/月份/计划状态查询列表，每条计划记录一个栋舍在指定日期的补栏信息，含养殖品种/补栏数量/苗重/预计出栏信息及三段养殖标准；提供「饲喂计划」弹窗查看该计划各段的日龄采食计划明细（含料号、配比）。需求明确本模块「只可以查看」，无新增/编辑/删除入口。

## 模块信息

- 禅道模块ID：`651`
- 原型路径：`/biopark-poultry/production/plan`
- module_complexity：`query_report`
- testpoint_template：`查询报表`

## 范围

### 范围内（in_scope）

- 查询（年份/月份/计划状态）
- 列表展示（计划编号/状态/补栏日期/栋舍/品种/数量/苗重/养殖天数/出栏日期/出栏体重/宰杀线/排程编号/三段养殖计划）
- 饲喂计划弹窗（引用型，查看该计划各段日龄采食计划明细）

### 范围外（out_scope）

- 计划新增/编辑/删除（来源产业链生产排程系统下推，本页不提供写路径）
- 排程下推逻辑本身（产业链生产排程系统职责，非本模块验收范围）

## 业务规则

- 计划数据来源：产业链生产排程系统下推，本页仅可查看，无需/无法新增修改
- 出栏日期 = 补栏日期 + 养殖天数（自动计算）
- 计划状态「待执行」：补栏日期晚于今天（与是否完成补栏确认无关）
- 计划状态「执行中」：补栏日期≤今天且尚未收到出栏结算单（与是否完成补栏确认无关）
- 计划状态「已完成」：已收到出栏结算单；查询默认全部
- 三段养殖计划（1/2/3段各含养殖天数、空栏天数、体重(g)、料比）随计划下推带出展示

## 原型要点

- 查询条件：年份、月份、计划状态
- 列表列（按序）：序号 → 计划编号 → 计划状态 → 补栏日期 → 补栏时间 → 栋舍 → 养殖品种 → 补栏数量 → 苗重(g) → 养殖天数 → 出栏日期 → 出栏体重(kg) → 宰杀线 → 排程编号 → 1段养殖计划 → 2段养殖计划 → 3段养殖计划 → 操作
- 关键按钮语义：
  - **饲喂计划**：行内操作按钮（非工具栏新增），弹出对话框展示该计划各段的日龄采食计划明细，含料号和配比
- 嵌套弹窗：
  - 饲喂计划（reference）：触发于 列表行「饲喂计划」操作按钮
- UI组件：pagination、cell_ellipsis_tooltip

## 总体关联（跨模块/外部系统）

- 产业链生产排程系统（排程下推，外部系统）：计划编号/上苗日期/栋舍/品种/补栏数量/苗重/出栏体重/宰杀线/排程编号/三段养殖标准/日龄采食计划均由该系统下推生成
- 补栏确认（REQ-003）：本模块计划记录为补栏确认主数据来源（计划编号/上苗日期/栋舍/品种，确认状态默认待发货）
- 跨模块引用明细：
  - 饲喂计划明细（弹窗） ← 产业链生产排程系统-分段养殖模版/制定排程（外部系统）（饲喂计划）

## 待澄清（open_questions）

- 排程下推数据缺失或延迟到达时，本页应如何展示（空值/占位/异常提示），需求未明确
