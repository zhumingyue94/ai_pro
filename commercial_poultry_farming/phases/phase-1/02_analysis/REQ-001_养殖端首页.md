# REQ-001 养殖端首页 — 需求分析摘要

> 本文档为 `REQ-001.yaml` 的可读摘要，字段以 YAML 为准。

## 概要

养殖员登录系统后的默认工作台（原型页面主标题 heading 实为「物联网监控中心」，浏览器/系统标题为「智慧园区管理平台」）。以栋舍为行的环境监控大表实时展示温湿度/通风/料塔等环控指标（原型可见23列），并提供列配置、按段区/栋舍排序切换、全屏等展示能力。需求 3.1.4 消息中心已明确「暂不加」，当前版本不建独立入口。

## 模块信息

- 禅道模块ID：`650`
- 原型路径：`/biopark-poultry/dashboard/farm`
- module_complexity：`query_report`
- testpoint_template：`查询报表`

## 范围

### 范围内（in_scope）

- 栋舍环境监控表（栋舍/段区/日龄/温湿度/通风/料塔余量/湿帘状态等环控与养殖指标实时展示）
- 列配置（拖拽调整列表项显示顺序、自定义显示/隐藏列）
- 切换排序（按段区排序/按栋舍排序）
- 全屏/退出全屏（环境监控表全屏展示）

### 范围外（out_scope）

- 数据颜色预警规则（需求标注「待定，先不加颜色标识」）
- 体感温度实际计算（需求标注「先留位不用计算」，计算方式在垂直/纵向通风方案下不一定适用）

## 业务规则

- 平均温差 = 平均温度 - 目标温度
- 前后温差 = 前区温度 - 后区温度
- 体感温度 = 平均温度 + (平均湿度-目标湿度)*湿热系数 - 风速*风冷系数；风速=栋舍内每秒排风量/栋舍截面积；每秒排风量=运行风机数量*风机功率(h)/3600；截面积=栋舍宽*屋檐高+栋舍宽*(屋顶高-屋檐高)/2；需求注明当前「先留位不用计算」
- 目标温度、目标湿度、湿热系数、风冷系数取自养殖标准（REQ-007，按品种+日龄匹配）
- 平均温度、平均湿度、舍外温度等为采集数据，来自环控系统上传；舍外温度亦可取官方天气数据
- 运行风机数量、风机功率、栋舍宽/屋檐高/屋顶高等来自园区基础信息-栋舍信息（用于风速计算，当前未启用）
- 段区标签（1段/2段/3段）按段区着色
- 数据颜色预警规则待定，暂不加颜色标识
- 消息中心（需求3.1.4）已明确「暂不加」，当前版本首页不含独立消息中心入口

## 原型要点

- 页面壳层标题（heading）：物联网监控中心
  - 说明：浏览器/系统标题为「智慧园区管理平台」（通用壳层），页面主标题（heading）实为「物联网监控中心」，与需求文档标题「养殖端首页」不同名同页，测点应以实际 heading 文案为准
- 列表列（按序）：栋舍 → 段区 → 日龄 → 目标温度 → 体感温度 → 平均温度 → 平均温差 → 舍外温度 → 舍内外温差 → 前区温度 → 中区温度 → 后区温度 → 前后温差 → 舍内湿度 → 二氧化碳 → 小窗左｜右 → 负压 → 温控｜上限 → 通风级别 → 开｜关 → 运行风机 → 料塔余量 → 湿帘1
- 关键按钮语义：
  - **列配置**：支持拖拽调整列表项显示顺序、自定义哪些显示哪些不显示
  - **按段区排序**：按段区排序/按栋舍排序切换（原型工具栏文案「按段区排序」，对应需求「切换排序」）
  - **全屏**：环境监控表全屏展示，再次点击退出全屏

## 总体关联（跨模块/外部系统）

- 养殖标准（REQ-007）：按品种+日龄提供目标温度/目标湿度/湿热系数/风冷系数，供本页体感温度公式与段区着色使用
- 环控系统（IoT，外部）：栋舍环境采集数据上传（温度/湿度/CO2/负压/通风级别/运行风机/料塔余量/湿帘状态）
- 官方天气数据接口（外部）：舍外温度备选来源
- 园区基础信息-栋舍信息：风机功率、栋舍宽/屋檐高/屋顶高（体感温度风速计算用，当前未启用）
