# REQ-006 出栏结算 — 需求分析摘要

> 本文档为 `REQ-006.yaml` 的可读摘要（**v3**，v2 原型实核 + 2026-07-20 风险/待澄清产品澄清），字段以 YAML 为准。

## 概要

养殖管理下的出栏结算页。数据来源标注为自动同步云星瀚（食品结算单、成品入库）。按栋舍养殖批次、出栏月份查询；列表展示结算指标与计算列；「详情」只读查看结算头信息与成品入库明细；支持导出。

**重要**：需求 3.6.5 写有「新增/编辑」，但 2026-07-16 原型**无**新增/编辑入口（仅查询/重置/导出/详情）。本版按原型将复杂度定为 `query_report`，写路径不纳入可测 in_scope。

## 业务规则（公式）

| 字段 | 公式 |
|------|------|
| 均重(kg) | 结算重量 / 结算只数 |
| 饲养天数 | 结算日期 − 补栏日期 |
| 日增重(g) | 均重 × 1000 / 饲养天数 |
| 成活率(%) | 结算只数 / 上苗数量 × 100% |
| 料肉比 | 总料量 / 结算重量 |
| 欧指 | (均重 × 成活率) / (料肉比 × 出栏日龄) × 10000 |
| 出栏日龄 | = 饲养天数 = 结算日期 − 补栏日期 |

- 结算日期始终等于出栏日期（与财务推送时刻无关）
- 上苗数量 ← REQ-003；总料量 ← REQ-005 **补栏日～出栏日**累计吃料
- 不强制结算只数 ≤ 上苗数量
- 数据来源：财务系统推送；**无**新增/编辑

## 原型要点

### 页面壳

- 菜单：养殖管理 → 出栏结算

### 列表列

序号、栋舍、栋舍养殖批次、结算日期、结算只数、结算重量(kg)、上苗数量、均重(kg)、总料量(kg)、饲养天数、日增重(g)、成活率、料肉比、欧指、操作

### 结算详情（只读）

- 头信息：栋舍、批次、结算日期、结算只数/重量、上苗数量、均重、总料量、饲养天数、日增重、成活率、料肉比、欧指
- 子表「成品入库明细」：序号、产品编号、产品名称、规格、数量、单价（样例含鸡胸肉/鸡腿/鸡翅等）
- 无表单按钮；关闭靠遮罩/Esc

## 风险 / 待澄清

- 新增/编辑是未上线、权限隐藏还是已取消手工登记
    - 澄清：
        - 出栏结算是财务系统推送过来的，没有新增编辑功能
- 出栏日龄 vs 饲养天数
    - 澄清：
        - 出栏日龄 = 结算日期-补栏日期
        - 饲养天数 = 结算日期-补栏日期
        - 结算日期始终等于出栏日期，和财务系统推送结算单的时间无关
- 总料量取数时点
    - 澄清
        - 补栏日期~出栏日期累计的日吃料量（关联饲养日志）
- 结算只数是否强制 ≤ 上苗数量
    - 澄清：
        - 不用强制校验结算只数 ≤ 上苗数量
- 同步与将来手工登记冲突规则
    - 澄清：
        - 没有手工登记功能，以后有异常需要手工登记处理，以手工点击的数据为主
