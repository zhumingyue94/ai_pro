# REQ-005 饲养日志 — 需求分析摘要

> 本文档为 `REQ-005.yaml` 的可读摘要（**v5**，定时生成 + 仅编辑；对齐 `需求变动.md`：已完成补栏计划锁定编辑）。

## 概要

养殖管理下的饲养日志页。日志由**定时任务**按栋舍段区自动生成（**无「新增记录」「删除」**）；查询 + 树形列表；行内**仅编辑**。死亡/淘汰从死淘巡检同步只读；转运体重/饮水/吃料机读可改。关联补栏计划为「已完成」时禁止编辑。

## 范围

### 范围内

- 查询：养殖日期（范围，默认当日）、栋舍、段区；查询 / 重置
- 树形列表 + 分页；行内**仅编辑**（计划未完成时）
- 工具栏：注释说明、日报表导出
- 定时生成日志（有批次栋+段；发货状态条件见 generation_rules）
- 编辑饲养日志；饲料吃料量子表；注释说明；日报表导出
- 已完成补栏计划锁定编辑

### 范围外

- 手工新增记录 / 删除
- REQ-007 标准维护；REQ-008～009 报表；REQ-006 结算逻辑本体

## 业务规则

- 定时生成；有批次的栋+段才生成；无批次段区不生成
- 发货状态已发货/已签收才生成；待发货/发货中不生成；变为已发货当日补齐历史日龄日志
- 已发货时 0 日龄存栏数取发货总量（不论是否确认）
- 补历史日死淘取对应日巡检实际值，无巡检则死淘=0
- 存栏递推：0日龄=上苗数；n日龄=前一日存栏−前一日死淘
- 死亡/淘汰/日吃料量/日饮水量均以本条日志生成时间为界；超时计入次日
- 日死亡/淘汰 = 巡检汇总（生成时间前）；编辑不可改
- 日死淘 = 死亡 + 淘汰；存栏/成活率按上苗与累计死淘
- 料肉比 = 只累计吃料量 / 转运体重（空体重→空）；编辑历史吃料影响日累计采食量与料肉比
- 饲料来自审核通过排程的日龄采食计划；吃料量可改
- **关联补栏计划「已完成」（已收到出栏结算单）→ 子行「编辑」不可用**；执行中/待执行仍可编辑

## 原型要点（v5）

- 工具栏：`注释说明`、`日报表导出`（无新增记录）
- 行操作：`编辑`（无删除；计划已完成时禁用/隐藏）
- 编辑头区只读；死淘只读；机读字段可改；按钮取消/确定

## 测试范围建议

- P1：生成可见、编辑保存、树汇总、日死淘、巡检一致、日吃料；发货存栏/补历史；**已完成计划编辑不可用**
- P2：查询、机读/空零、饲料表、料肉比、**执行中仍可编**、并发；死淘/吃料/饮水截止分字段
- P3：注释、导出、分页
- **禁止**：测「新增记录」「删除」入口；把死亡/淘汰写成可编辑必填；保留「结算后仍可编辑」旧口径

## 澄清（已落地）

- 已完成补栏计划不允许编辑日志（需求变动；反转原「结算后不锁定」）
- 体重与只当前体重同一取数（料肉比用转运体重）
- 饲料带来源：审核通过排程日龄采食
- 列表无 V1.1 累计列
