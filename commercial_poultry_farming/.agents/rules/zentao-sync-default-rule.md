# 禅道同步默认执行策略规则

## 定位

本规则约束禅道用例同步阶段的**默认执行模式**与**配置读取来源**，适用于根目录下所有项目。
它只定义通用策略，不包含任何项目名、业务模块、业务字段、真实 URL、ZenTao ID 或需求编号。

## 默认执行模式

禅道用例同步任务**默认执行真实创建**，不使用 `dry-run`，也不需要为每次任务重复征求写入授权。

例外：任务描述中出现以下任一表述时才退回 `dry-run`：

- 显式包含 `dry-run`、`试运行`、`只生成证据`、`不写入远程` 等字样；
- 要求先评审同步载荷或先确认字段映射。

## 配置读取优先级

同步目标参数的取值顺序，靠前者覆盖靠后者：

1. 任务描述中显式给出的参数；
2. 项目 `config.yaml` 中声明的禅道目标字段；
3. 需求模块拆分清单中该需求对应的模块归属；
4. 上述均缺失时，停止同步并向用户提问，不得猜测或回退默认值。

### 产品与项目

- 用例导入目标按以下优先级解析：任务提示词中显式指定的目标 > 项目 `config.yaml` 中的 `zentao_import_target`。
- 任务提示词未显式指定目标时，必须读取并遵循 `config.yaml` 的 `zentao_import_target`；不得自行猜测、硬编码或覆盖配置值。
- `zentao_import_target` 为产品库时，使用 `zentao_product_id` 作为写入范围；为项目库时，使用 `zentao_project_id` 作为写入范围，并保留 `zentao_product_id` 作为产品上下文校验。
- 配置缺失、值不支持或目标范围无法可靠确认时，停止同步，不得执行创建、更新或删除。

### 模块

- 用例所属模块必须从需求模块拆分清单中该需求**指定的依赖模块**读取，使用该业务模块 ID。
- **禁止回退到父级模块**或就近的上级目录模块作为所属模块。
- 模块拆分清单中的依赖数据（基础数据、上游单据等）只记录为数据契约或依赖上下文，不得当作所属模块 ID。

## 字段映射与命令约束

- 多步骤用例必须为每个步骤分别传递一个 `--steps` 和一个 `--expects` 参数，不得把多个步骤拼接为逗号字符串，也不得依赖未验证的 JSON `--data` 数组映射。当前安装的 CLI 创建参数名为 `--productID`，不得误用 `--product`。
- 中文参数必须通过以 UTF-8 BOM 保存的 PowerShell 脚本传递给 `zentao`，项目统一使用 `scripts/zentao_create_testcase.ps1`；禁止从可能按 GBK 解码的 shell 直接传递中文写入远程。
- 测试用例 YAML 的本地 `type` 仅允许 `interface`、`feature`、`install`、`config`、`performance`、`security`；禁止使用 `unit`，`negative`、`boundary`、`functional`、`data_consistency`、`permission` 和 `other` 不得作为新的本地类型。
- 仅通过页面观察反馈、控件和状态归为 `feature`；明确调用或校验 API、请求响应或字段协议归为 `interface`；其他类型按安装部署、配置、性能或安全验证对象归类。
- 非法或缺失本地 `type` 必须在远程写入前阻断，不得回退为 `feature`。
- 测试用例 YAML 的 `auto: "auto"` 不写入任何禅道关键词，并将禅道用例 `type` 设置为 `other`（其他）。
- 测试用例 YAML 的 `auto: "no"` 不写入关键词，且保留 YAML 中原有的合法禅道用例类型映射。
- 回读校验不检查关键词；对 `auto: "auto"` 用例校验禅道 `type=other`。

## 执行流程

按“创建/更新/删除一条 → 回读一条 → 校验一条 → 更新注册表一条”逐条推进：

1. 在解析出的目标测试库中处理单条用例；
2. 立即回读该条，校验目标库范围、远程 ID、需求关联、模块归属和关键字段；
3. 校验通过后，才允许将禅道数字 ID 写入注册表；
4. 校验不通过即停止剩余用例，不得继续批量处理。

## 状态与失败处理

| 情况 | 记录状态 |
|---|---|
| 未执行远程写入 | `not_executed` |
| 远程失败、权限不足、回读不完整 | `blocked` |
| 已创建但注册表尚未确认写入 | `pending_registry` |

- **禁止生成临时 ID、占位 ID 或推测 ID**冒充禅道数字 ID。
- 没有真实远程回读的用例，其禅道用例 ID 必须为 `null`。

## 公共入口与项目旁路

- 所有项目的创建、更新、删除必须经 `scripts/zentao_create_testcase.py` 公共入口；项目级 `06_zentao_sync` 脚本只能负责输入定位、范围选择和证据包装。
- 项目级脚本不得直接调用禅道 CLI、构造远程 payload、实现回读校验或维护第二套注册表；公共入口配置缺失时不得执行远程写入。
- `precondition` 字段值只包含“前置准备：”和“前置步骤：”分区；“前置条件”是禅道字段标题，不得重复写入字段值。
- 删除只能经公共入口执行：必须指定正整数 `--delete-case-ids` 清单，并同时提供 `--delete` 和 `--confirm-delete`；`--dry-run` 仅用于计划模式，禁止与真实删除确认同时使用。禁止标题模糊匹配、按模块全量删除或删除其他产品、项目、模块范围的用例。
- 删除必须逐条回读并校验产品、项目、模块及稳定映射关系；真实模式调用删除命令后立即回读，只有明确确认目标不存在才算成功，并从唯一注册表当前用例集合中直接移除对应映射。删除历史必须保留在同步执行日志、回读证据和交接记录中；任一步骤失败即停止且不得移除未确认成功的映射。

## 不可省略的约束

- 不改写原始测试步骤和预期结果。
- 只更新项目根目录唯一注册表文件，不创建第二套注册表。
- 执行前后校验来源哈希；输入发生变化时停止真实同步。
- 只在用户明确指定的用例范围内创建，不得扩大范围。
- 账号、密码、Token、Cookie 只从环境变量或安全交互读取；不打印、不保存、不写入证据文件。

## 适用环节

| 环节 | 要求 |
|---|---|
| 禅道同步 | 默认真实创建，按本规则读取目标并逐条回读 |
| 注册表更新 | 仅回读校验通过后写入禅道数字 ID |
| 交接文档 | 记录实际执行模式、目标库类型、模块依据和回读状态 |
