## 2026.08.12更新
### 制定排程（REQ-004）— 日期推算规则

根据最新需求，排程日期按以下规则计算：

- 补栏日期 = 宰杀日期 - 总养殖天数 + 1
- 上孵日期 = 补栏日期 - 孵化周期
- 1段转进日期 = 补栏日期
- 2段转进日期 = 补栏日期 + 1段养殖天数
- 3段转进日期 = 补栏日期 + 1段养殖天数 + 2段养殖天数
- 转出日期 = 转进日期 + 养殖天数 - 1
- 空栏结束日期 = 转进日期 + 养殖天数 + 空栏天数 - 1
- 释放日期 = 空栏结束日期
- 宰杀日期 = 出栏日期 = 3段转出日期

上述转出日期、空栏结束日期和释放日期规则中的“转进日期”“养殖天数”“空栏天数”均指当前段自身对应的数据，不引用其他段的数据。

### 制定排程（REQ-004）— 栋舍智能分配

> 原型页面：`/biopark-poultry/schedule/plan-schedule/make-plan/create/add`（制定排程设置页）

#### 一、日计划编辑区新增入口

选中月度看板某一日期后，右侧「日计划编辑」标题栏新增三个辅助按钮：

| 按钮 | 作用 |
|------|------|
| **栋舍分配策略配置** | 设置默认栋舍分配策略 |
| **栋舍排程明细** | 打开「栋舍排程视图」弹窗，查看栋舍占用 |
| **智能推荐** | 打开「智能分配」弹窗（与点击「养殖栋舍」等价） |

#### 二、养殖栋舍字段变更

- **原行为**：系统自动分配，字段只读展示。
- **新行为**：
    - 占位符「点击分配栋舍」，可点击打开「智能分配」弹窗选手动分配。
    - 旁侧提供「智能推荐」快捷按钮。
    - **可编辑状态**：待排、暂存、驳回。
    - **只读状态**：待审核、已下推（养殖栋舍与智能推荐均 disabled）。
    - **前置门禁**：须先选择养殖品种并生成补栏日期；否则提示「请先选择养殖品种并生成补栏日期，再进行栋舍分配」。

#### 三、栋舍分配策略配置弹窗

- 策略仅 **2 种**（与得分说明 docx 一致）：
    - **栋舍顺序优先**（默认）：全周期无冲突时按栋号升序分配，保持动线连续。
    - **最小空闲优先**：全周期无冲突时优先消杀释放后可立即衔接的栋舍。
- 说明文案：「默认策略会自动应用到后续新增的宰杀线排程；已创建的排程仍可单独调整。」
- 操作：「保存默认方案」「取消」/关闭。
- 保存后作用于**后续新增**宰杀线排程的默认推荐策略；已创建排程可单独在智能推荐中调整。

#### 四、智能推荐 / 智能分配弹窗

- 左侧：当前计划三段周期（转进/转运/养殖天数/消杀/释放日）、全周期校验、「选择 X 栋」、分段校验明细。
- 右侧：推荐策略切换（栋舍顺序优先 ⇄ 最小空闲优先）、统计摘要（最优推荐 / 全周期可分配 / 存在冲突）、候选栋舍列表（按推荐优先级排序）。
- 候选标签：**最优推荐** / **可分配** / **时间冲突**；冲突栋舍不可选，可查看冲突段位。
- 匹配度得分计算见 `栋舍分配最小缓冲与推荐得分逻辑说明.docx`：
    - **前提**：三段养殖+消杀均无重叠；有冲突 → 时间冲突，不参与推荐。
    - **栋舍顺序优先**：`score = max(0, 100 - d×5)`，`d = 候选栋号 - 最小可用栋号`。
    - **最小空闲优先**：`score = max(0, 100 - MinGap×5) × 80% + SeqScore × 20%`。

#### 五、栋舍排程明细 / 栋舍排程视图弹窗（2026-07-31 补探）

- 入口按钮「栋舍排程明细」→ 弹窗标题「栋舍排程视图」。
- **筛选区**：年份、月份下拉（默认与制定页计划月份一致）；展示「共 N 栋」。
- **图例**（三视图共用）：1段、2段、3段、消杀。
- **三视图 Tab**：
    1. **明细表格**（默认）：列含栋舍、状态；1段育雏（补栏日期/转出日期/释放日期）；2段育成、3段育肥（转进日期/转出日期/释放日期）。
    2. **甘特视图**：查询月份前后一个月；支持缩小/标准/放大；纵轴「栋舍/段」，横轴月份刻度与「今日」标线；条块展示养殖天数、消杀天数、间隔天数。
    3. **月度热力日历**：可切换上月/当月/下月；纵轴栋舍·段，横轴 1~31 日；单元格表示日级占用（悬浮含栋号·段次·日期）。
- 关闭方式：弹窗右上角 ×；无底部操作栏。
- **待澄清**：
    - 明细表格「暂无数据」时甘特/热力仍有数据：明细表格只是当月数据为空，甘特/热力图是横跨几个月份所以会有其他月份数据
    -「共 0 栋」计数口径——测试造数阶段核对，若确认为缺陷则提 Bug：明细表格是暂无数据就会显示共0栋，表格有数据就不可能是共0栋
