# 新项目 QA 工程搭建操作说明书

本说明书用于根据当前公共契约创建独立 QA 项目。只复用目录形状、阶段接口和通用规则；业务模块、页面、账号、密码、URL、禅道 ID 和执行结果必须由当前项目实际提供。

## 目录与流程

```text
01_requirements/                         原始需求输入
02_analysis/                             requirements-analysis-agent
03_test_plan/                            test-plan-agent
04_testcases/                            testcase-generation-agent
05_case_review/                          case-review-agent
06_zentao_sync/ + module_case_map.json   zentao-sync-agent
07_ui_automation/                        automation-agent + 缺陷报告
08_bug_verification/                     bug-verification-agent
09_regression/                           regression-agent
```

当前仓库不包含测试点和测点评审目录、Schema 或阶段产物；新项目不得创建这些目录。


## 填入项目身份（禅道 / 环境 / 菜单）

**你自己做：**

1. 把需求文档放入 `01_requirements/`
2. 在禅道确认产品 ID、项目 ID、模块树、用例导入模板
3. 能登录原型与测试环境



### 1. 禅道同步统一入口

新项目必须在 `config.yaml` 中声明 `zentao_sync.entrypoint: "../../scripts/zentao_create_testcase.py"`、`implementation: "shared"`、`allow_project_cli: false`，并启用回读、注册表和来源哈希校验。项目的 `06_zentao_sync` 脚本只能定位输入、选择范围和输出证据，不得直接调用禅道 CLI或自行构造同步载荷。

### 2. 保存禅道的登录脚本

```
请使用 Python + Playwright 创建一个独立的禅道登录脚本。

创建文件：
- `../../scripts/login_zentao.py`

要求：

1. 启动可见 Chromium 浏览器，固定 `headless=False`。
2. 禅道地址从系统环境变量 `ZENTAO_URL` 读取。
3. 账号从 `ZENTAO_ACCOUNT` 读取。
4. 密码从 `ZENTAO_PASSWORD` 读取。
5. 访问禅道并等待页面完成加载。
6. 读取当前页面真实 DOM，确认账号输入框、密码输入框和登录按钮。
7. 使用环境变量填写账号和密码并点击登录。
8. 通过当前 URL、登录页是否消失或真实页面元素判断登录结果。
9. 存在验证码、二次验证或无法确认登录控件时，记录为 `blocked`，不得猜测或绕过。
10. 不打印、保存或截图输出账号、密码、Token、Cookie。
12. 不读取、创建、修改禅道测试用例、测试单、Bug 或其他业务数据。
13. 脚本必须能脱离 AI 独立运行。
14. 支持命令：

python ../../scripts/login_zentao.py --help
python ../../scripts/login_zentao.py


```
