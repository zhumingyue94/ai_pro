# 产业链生产排程系统项目业务约定

通用 QA 流程、阶段门禁、安全、证据和公共资源约定见根目录 [`../../AGENTS.md`](../../AGENTS.md)。本文件只保留本项目业务专属约定，不重复公共内容。

## 项目业务约定

- 项目名：产业链生产排程系统。
- 禅道连接运行时从系统环境变量读取：`ZENTAO_URL`、`ZENTAO_ACCOUNT`、`ZENTAO_PASSWORD`。
- 目标产品：产业链排程系统，产品 ID 为 `6`。
- 目标项目：产业链排程，项目 ID 为 `38`。
- 禅道导入目标：项目。
- 默认 UI 测试环境：`http://192.168.6.163:66`。
- UI 测试 URL、账号、密码和租户运行时从仓库根目录 `.env` 或系统环境变量读取：`UI_TEST_URL`、`UI_TEST_USERNAME`、`UI_TEST_PASSWORD`、`UI_TEST_TENANT`；不得保存或使用 Playwright storage state。
- 门户进入路径：产业链生产排程系统。
- 用例登录前置描述：使用智控中心测试账号登录。
- 自造测试数据前缀：`AUTO测试_勿用_`；建议追加 RUN 标识，避免跨次执行复用。
以下内容仍由项目使用者补充：

- 需求来源及权限边界
- 测试数据清理审批人
- 阶段负责人和验收标准
