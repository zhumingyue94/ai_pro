## 摘要

宰杀线主数据：查询、新增/编辑（含**单日产能(万只)**、**排序**）、启停、批量删除。无审核/查看/中台同步。编码前缀似 SL…（与饲料撞型）。栋舍「关联线体」疑似引用本模块。

## 范围内 / 外

**In**：查询重置、增改、启停、批量删、列表分页刷新表头、产能/排序字段  
**Out**：中台同步、其它基础数据菜单、排程看板消费细则  

## 业务规则（摘录）

1. 状态：启用 / 停用  
2. 新增：编码预填可改，名称必填 →「宰杀线名称不能为空」  
3. 编辑：编码只读  
4. 停用确认：「确定要停用该宰杀线吗？」  
5. 启用删除拦截：同类 toast（本页待执行复核）  

## 测试范围建议

| 优先级 | 建议 |
|--------|------|
| P1 | 新增；编码只读；停用确认；删除拦截复核 |
| P2 | 查询/重置；产能/排序；批量启停 |
| P3 | 分页、刷新、表头 |

节点：`查询 → 新增 → 表格 → 编辑 → 启停 → 删除`（无同步）
