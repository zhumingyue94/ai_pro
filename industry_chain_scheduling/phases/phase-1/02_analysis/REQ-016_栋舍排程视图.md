# REQ-016 栋舍排程视图

## 新增模块与范围

REQ-016 来自模块拆分清单中的“排程看板 / 栋舍排程视图”（禅道模块 719），页面路径为 `/biopark-poultry/schedule/barn-schedule-board`。产品需求文档原始功能模块表未单列该页面，但后续原型/需求变更已明确其为独立视图。本次只分析该模块，不回分析其他非排程看板模块。

范围包括年/月筛选、默认明细表格、甘特视图、月度热力日历、图例、栋舍计数、空态、月份切换、缩放和 tooltip；不包括新增/编辑排程、智能推荐、栋舍策略配置和图表直接编辑。

## 页面契约

- 默认筛选月份与制定排程计划月份一致，展示“共 N 栋”。
- 明细表列出栋舍、状态及 1/2/3 段转进/转出/释放日期。
- 甘特视图查询月份前后一个月，展示栋舍·段、月份刻度、今日线、养殖/消杀/间隔天数，支持缩小/标准/放大。
- 热力日历可切换上月/当月/下月，横向 1~31 日，tooltip 至少包含栋号、段次、日期。
- 明细表当月无数据时可以显示“共 0 栋”，但甘特/热力跨月仍可能有其他月份数据；这是视图口径差异，不能直接判定为数据缺失。
- 关闭为右上角关闭，无底部操作栏。

## 最新日期基线

以最新《排程计算.xlsx》为后续分析基线：1 段转进为补栏日，转出为补栏日加本段养殖天数减 1，释放再加本段空栏天数；2/3 段转进分别承接前一段转出，转出/释放按累计养殖天数和本段空栏天数计算；同一栋舍下一批计划遵循释放日次日方可转进。历史材料对转运日归属存在不同描述，应按该最新基线保留并在接口确认前标为风险。

## 依赖、风险、待确认

依赖 REQ-003、REQ-004、REQ-005、REQ-010 和 REQ-015。风险是日期基线偏移、跨月空态与计数口径误读、31 日/时区边界、缩放性能和 tooltip 字段缺失。待确认“共 N 栋”口径、释放/转运/空栏条块边界、tooltip/空态字段，以及新增 REQ-016 的产品/禅道验收边界。
