## 摘要

基础数据下的饲料主数据维护：查询、新增/编辑、启停、批量删除。无审核、无独立查看、**无「同步数据」入口**（与品种/栋舍不同）。编号编辑只读、启用态不可删规则与品种同类。

## 范围内 / 外

**In**

- 查询（饲料编号、名称、状态）+ 重置
- 新增 / 编辑弹窗与校验
- 行停用确认；批量启用/停用/删除
- 列表、分页、刷新、表头设置

**Out**

- 中台同步（本菜单无入口）
- 其它基础数据菜单
- 下游模版选料业务细节（仅交叉引用线索）

## 业务规则（摘录）

1. 状态：启用 / 停用  
2. 新增：编号预填可改，名称必填；空提交 →「饲料名称不能为空」  
3. 编辑：编号只读  
4. 启用态不可批量删除 → toast「选择的数据均为启用状态，无法删除」  
5. 停用确认：「确定要停用该饲料吗？」  

## 原型契约要点

| 块 | 结论 |
|----|------|
| form_field_specs | 编号新增可编/编辑只读；名称必填；状态必填；备注非必填 |
| button_semantics | 无同步；停用/删除拦截已定义 |
| nested_dialogs | skip（无二级弹窗） |
| role_coverage | skip |
| calendar_* | N/A |
| 查询备注 | 待确认，勿强写为已定查询字段 |

## Design Artifacts

- **状态机**：启用 ↔ 停用；启用→删除非法（toast）  
- **决策表**：查询组合、删除可否、批量按钮  
- **BVA**：名称/编号/备注空与长度  
- **组合**：查询三条件 `pict_eligible: false`  

## 测试范围建议（给 TestPoint）

| 优先级 | 建议 |
|--------|------|
| P1 | 新增成功；编辑编号只读；停用确认；启用删除拦截 |
| P2 | 查询/重置；批量启停 |
| P3 | 分页、刷新、表头、备注 |

功能节点建议顺序：

```text
查询 → 新增 → 表格 → 编辑 → 启停 → 删除
```

（无「审核」「查看」「同步数据」节点；数量带参考简单配置 10±5，按覆盖拆全可达标准 CRUD 精简规模。）
