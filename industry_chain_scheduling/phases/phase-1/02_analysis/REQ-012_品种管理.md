## 摘要

基础数据下的品种主数据维护：查询、新增/编辑、启停、批量删除，以及从**数据中台**同步源品种。无审核、无独立查看。中台同步接口当前异常，弹窗无有效数据；同步主路径测点保留并标注依赖接口。

## 范围内 / 外

**In**

- 查询（品种编码、名称、状态）+ 重置
- 新增 / 编辑弹窗与校验
- 行停用确认；批量启用/停用/删除
- 同步数据弹窗壳层及（接口可用时）提交同步
- 列表、分页、刷新、表头设置

**Out**

- 其它基础数据菜单（饲料/宰杀线/栋舍）
- 中台源数据维护
- 停用对排程下游的联动（未在页面证实）

## 业务规则（摘录）

1. 状态：启用 / 停用  
2. 新增：编码预填可改，名称必填，默认启用；空提交 →「品种名称不能为空」  
3. 编辑：编码只读  
4. 启用态不可批量删除 → toast「选择的数据均为启用状态，无法删除」  
5. 同步 = 中台选数 → 本系统；未勾选提交 disabled  

## 原型契约要点

| 块 | 结论 |

| form_field_specs | 编码新增可编/编辑只读；名称必填；状态必填；备注非必填 |

| nested_dialogs | 「同步数据」引用型多选；`depends_on_data_hub` |
| role_coverage | skip |
| calendar_* | N/A |

## Design Artifacts

- **状态机**：启用 ↔ 停用；启用→删除非法（toast）  
- **决策表**：查询组合、删除可否、批量按钮、同步提交  
- **BVA**：名称/编码/备注长度与空值  
- **组合**：查询三条件 `pict_eligible: false`；同步四参（接口可用）`pict_eligible: true`  

## 测试范围建议（给 TestPoint）

| 优先级 | 建议 |
|--------|------|
| P1 | 新增成功；编辑编码只读；停用确认；启用删除拦截 |
| P1 | 同步壳层 +（接口恢复后）勾选提交与源编码回填 |
| P2 | 查询/重置；批量启停；源品种编码展示 |
| P3 | 分页、刷新、表头、超长备注 |

功能节点建议顺序：

```text
查询 → 新增 → 表格 → 编辑 → 启停 → 删除 → 同步数据
```

（无「审核」「查看」节点。）
