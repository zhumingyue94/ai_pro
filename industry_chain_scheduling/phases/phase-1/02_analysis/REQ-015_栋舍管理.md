## 摘要

栋舍主数据：查询、新增/编辑（类型、关联线体手输、面积、设计容量）、启停、批量删除，以及**数据中台同步**。中台接口当前异常 → 弹窗无有效数据；表头实察含「品种名称」，恢复后复核是否缺陷。关联线体非引用弹窗。

## 范围内 / 外

**In**：查询重置、增改、启停删、同步壳层/（接口可用时）提交、列表分页等  
**Out**：宰杀线/品种/饲料主数据维护、中台源维护、补栏看板细则  

## 业务规则（摘录）

1. 状态：启用 / 停用  
2. 新增：编码 DS… 预填可改，名称必填 →「栋舍名称不能为空」  
3. 编辑：编码只读；关联线体可手输  
4. 停用：「确定要停用该栋舍吗？」  
5. 同步：中台勾选 → 本系统；未勾选提交 disabled  

## 测试范围建议

| 优先级 | 建议 |
|--------|------|
| P1 | 新增；编码只读；停用；删除拦截复核；同步壳层 |
| P1 | 接口恢复后：勾选提交、列名/回填（`depends_on_data_hub`） |
| P2 | 查询；关联线体；面积/容量；批量启停 |
| P3 | 分页、刷新、表头、备注痕迹 |

节点：`查询 → 新增 → 表格 → 编辑 → 启停 → 删除 → 同步数据`
