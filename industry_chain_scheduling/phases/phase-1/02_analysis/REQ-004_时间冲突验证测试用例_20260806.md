## 1. 冲突判定规则（来自 REQ-004.yaml）

决策表（L393-398）：
- `当前补栏日 > 上一计划1段结束日 且 本计划1段结束日 < 下一计划1段补栏日` → **分配成功（不冲突）**
- `当前补栏日 <= 上一计划1段结束日` → **与上一计划冲突**
- `本计划1段结束日 >= 下一计划1段补栏日` → **与下一计划冲突**

组合块（L522-534）：
- 与上一计划关系：`不冲突` / `补栏日重叠` → 重叠则分配失败
- 与下一计划关系：`不冲突` / `1段结束重叠` → 重叠则分配失败
- 同日多宰杀线：`否` / `是` → 同日多宰杀线同栋占用标记**时间冲突**（与 TP-004-62 一致）

弹窗呈现（来自 DOM 快照 + L189/L194）：
- 统计摘要：`最优推荐` / `全周期可分配` / `存在冲突 N 需调整时间节点`
- 候选栋舍卡片字段：`栋号 / 标签 / 匹配度分数 / 说明 / 排序 / 冲突段位`
- 冲突卡片文本：`时间冲突` + `不可分配` + `与既有计划的 N 段重叠` + `查看冲突段位 →`
- 图例：`最优推荐` / `可分配` / `时间冲突`

## 2. 段窗口计算模型（模板 42 天）

引用分段养殖模板：日龄 1-14 / 15-28 / 29-42，空栏 4 / 5 / 6 天；补栏当天为 0 日龄。
设补栏日 = `D`，则：

| 段 | 养殖区间 | 段结束日 | 占用释放（含空栏） |
|----|----------|----------|--------------------|
| 段1 | `[D, D+13]` | `D+13` | 至 `D+17` |
| 段2 | `[D+14, D+27]` | `D+27` | 至 `D+32` |
| 段3 | `[D+28, D+41]` | `D+41` | 至 `D+47` |

> 冲突引擎按「三段养殖 + 消杀（空栏）释放周期均无重叠」判定；卡片枚举**实际重叠的段位**。
> 因批次段连续且同模板，候选 N 与基准偏移较小时，段1/段2/段3 会**级联重叠**（同时命中多段）。故「仅单段」用例出现在边界（正好相差一个段结束日）处。

## 3. 基准「既有计划」定义（锚点 2026-08-06）

| 基准 | 栋舍 | 补栏日 D | 段1 `[D,D+13]` | 段1结束 | 段2 `[D+14,D+27]` | 段3 `[D+28,D+41]` |
|------|------|----------|----------------|---------|-------------------|-------------------|
| **上一计划 A** | B1 | 2027-02-03 | 2/3–2/16 | **2/16** | 2/17–3/2 | 3/3–3/16 |
| **下一计划 C** | B1 | 2027-03-25 | 3/25–4/7 | 4/7 | 4/8–4/21 | 4/22–5/5 |

候选计划 N：仅改变「补栏日」，其余引用同模板、同栋舍 B1。

无冲突区间（同时躲开 A 与 C，每段按"养殖天数+空栏天数"整体占用窗、空栏计入）：经整窗扫描 **N ∈ [2/23, 3/5]**（下界 2/23 由 A段3整窗释放决定，上界 3/5 由 C段3整窗起始决定；各段均留约 1 天间隔）。

## 6. 断言要点

- 弹窗图例三态（`最优推荐`/`可分配`/`时间冲突`）可见。
- 冲突卡片同时包含：`时间冲突` + `不可分配` + `与既有计划的 N 段重叠` + `查看冲突段位 →`。
- 冲突卡片**不可选中**（点击无反应 / 禁用）。
- 负向用例（TC-C05、TC-C08）：卡片为 `可分配` 或 `最优推荐`，且**不出现**时间冲突标签。
- 边界用例严格按 `<=` / `>=` inclusive：`TC-C03`、`TC-C07` 应冲突；`TC-C08` 不冲突。
- 统计一致性（TC-C10）：摘要「存在冲突 N」中的 N 与实际冲突卡片数量一致。
- 段位明细（TC-C11）：「查看冲突段位 →」展开后，对应段位标红/失败。
