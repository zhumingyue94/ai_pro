- **BR-003**：1、二级蛋蛋库存中，只有一种类型的仓库：二级蛋蛋库； 2、根据登录账号权限范围不同，展示不同孵化场下的仓库； 3、确定一种蛋的字段包括：养殖场、养殖批次、品种、产蛋日期、蛋重类型、平均蛋重、周龄、种蛋类型； 4、二级蛋蛋库存中种蛋类型：二级蛋；依据关联仓库类型进行判断；（live prototype annotation / related requirement page）
- **BR-004**：关于库位的说明： 1、库位号系统根据规则自动生成，此处暂不详述生成规则； 2、仓库列表展示顺序遵循：①孵化场③仓库④库位号顺序； 3、库位分为①主库位②虚拟副库位； 4、主库位即为仓库新建时根据排列参数设置，自动生成的带有库位号的实际库位； 5、虚拟副库位：当一个主库位上入库了不同种类的蛋时，自动生成虚拟库位，有N种蛋即生成N个虚拟库位，此时主库位上不挂任何一种蛋的库存数据，即主库位不显示库存；（live prototype annotation / related requirement page）
- **BR-005**：库位状态： 1、库位状态只展示在主库位上； 2、全部状态包括：空位、未满、满容、超容、停用； 3、空位：该库位当前没有存放种蛋，无数据； 4、未满：该库位当前种蛋存放数据，没有达到库位容量； 5、满容：该库位当前种蛋存放数据，且刚好达到库位容量； 6、超容：该库位当前种蛋存放数据，且超过了库位容量； 7、停用：该库位当前被操作了停用操作。 仓库容量：30000 库位数：30 库位托盘数：10 托盘容量：100 库位容量：1000（live prototype annotation / related requirement page）
- **BR-006**：仓库标准容量信息展示，取自基础数据配置，此部分内容，只有筛选一个仓库的时候显示，如果是多个仓库，则不展示数据，展示“- -”。（live prototype annotation / related requirement page）
- **BR-007**：种蛋状态+上孵日期： 1、上孵日期：为该种蛋在上孵计划中已经定下来的计划上孵日期，实时更新，同一计划，取最新一次计划上孵日期； 2、如果还没有关联上孵计划，则不展示上孵日期；如果关联多个上孵计划，则展示多个上孵日期； 3、种蛋状态：待排期、待孵期、待上孵、已超期； 4、待排期：当前种蛋没有关联上孵计划，没有上孵日期； 5、待孵期：当前种蛋已经关联了上孵计划，但是还没有到上孵日期，还没有生成并下发上孵任务； 6、待上孵：当前种蛋已经关联了上孵计划，并且当日已经是上孵日期，已经下发了上孵任务，并且还没有执行完成上孵任务； 7、已超期：当前种蛋已经关联了上孵计划，并且已经下发了上孵任务，且过了上孵日期还没有执行完成上孵任务； 8、系统上可能会出现同一种蛋关联多个不同的上孵计划的可能性，关于种蛋状态展示优先级顺序：待上孵——已超期——待孵期——待排期； 9、种蛋状态，展示在有种蛋存储数据的车位上，无数据的为空。（live prototype annotation / related requirement page）
- **BR-008**：关于每行操作的说明： 1、每行的操作（入库、出库、记录、盘点、停用、启用），仅针对并涉及该行数据/库位进行操作； 2、入库：①主库位有入库操作按钮，虚拟库位没有，点击弹框/跳转进行入库操作；②入库不受库位容量限制，可以超容入库；③入库如果与库位中原有种蛋，是同一种种蛋，则合并入同一个库位，包括主库位和虚拟库位，如不是同一种种蛋，则划分虚拟库位； 3、出库：如果库位上有种蛋数据，则有出库操作按钮，点击弹框/跳转进行出库操作；如果库位上没有种蛋数据，则没有出库操作按钮； 4、盘点：①当只有主库位时，有盘点操作按钮，点击弹框进行盘点操作；②如果有虚拟库位，则在虚拟库位上有盘点操作按钮，主库位上没有盘点操作； 5、记录：①记录操作，是该主库位的历史出入库记录，点击跳转该库位的历史出入库记录页；②主库位有记录操作，虚拟库位没有记录操作； 6、停用：只有空位状态下的主库位，才有停用操作； 7、启用：只有停用状态下的主库位，才有启用操作。（live prototype annotation / related requirement page）
- **BR-009**：关于批量操作的说明： 1、批量入库时，最多只能勾选30个库位； 2、入库：①此为多库位批量入库操作，只有选择了库位，才会点击有弹框入库操作，即使只选择了一个库位，也可触发同样的弹框操作，否则弹框提示“请选择库位”；②只可选择同一个仓库的库位，只可入一种种蛋，否则则弹框提示“只可批量入库同一个仓库的库位”；③入库操作只会默认操作在主库位上，无视虚拟车位； 3、出库：①此为多库位批量出库操作，只有选择了库位，才会点击有弹框出库操作，即使只选择了一个库位，也可触发同样的弹框操作，否则弹框提示“请选择库位”；②批量出库操作不区分孵化场、仓库； 4、盘点：①此为多库位批量出库操作，只有选择了库位，才会点击有弹框盘点操作，即使只选择了一个库位，也可触发同样的弹框操作，否则弹框提示“请选择库位”；②批量盘点操作不区分孵化场、仓库； 5、启用/停用：①批量启用/停用操作，只有选择了库位，才会惦记有弹框操作，否则弹框提示“请选择库位”；②操作时，进行判断所选库位是否符合条件，如果不符合，则无法操作并弹框提示； 6、导出：导出选中库位的库位信息表，如果没有选中也可导出，默认全选操作。（live prototype annotation / related requirement page）
