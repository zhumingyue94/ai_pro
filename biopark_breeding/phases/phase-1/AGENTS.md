# 项目目录约定

本文件仅适用于项目 `种禽孵化管理系统`，不约束其他项目或目录。

## PC/App 产物分层

编号环节 `01_requirements`～`09_regression` 均按终端平台划分为：

```text
<环节目录>/
├── pc/       # PC 端专属产物
└── app/      # App 端专属产物
```

所有能够明确归属平台的产物必须放入对应目录，禁止把 PC 端和 App 端产物混放，也禁止将平台专属产物直接放在环节根目录。适用范围包括需求材料、分析结果、测试计划、测试用例、评审结果、同步资料、自动化产物、Bug 验证资料和回归资料。

## 共享文件例外

无法区分平台且确实被两个平台共同使用的文件，可以放在环节根目录，例如流程图、跨平台配置和共享脚本。文件若可以明确归属 PC 或 App，即使内容格式相同，也必须分别放入 `pc/` 或 `app/`。

`07_ui_automation` 下的共享配置、页面对象、工具代码可以继续放在环节根目录；平台专属的自动化脚本、报告、截图、Trace、日志及其他证据放入 `07_ui_automation/pc/` 或 `07_ui_automation/app/`。

`reference/` 是跨环节参考资料目录，不属于 `01`～`10` 的平台环节，不要求拆分为 `pc/` 和 `app/`。

## 新增和检查规则

- 新建或生成环节产物前，先确认其平台归属并写入对应的 `pc/` 或 `app/` 目录。
- 评审、同步、自动化和报告类产物同样遵循平台目录约定。
- 仅当文件明确是跨平台共享内容时，才允许放在环节根目录。
