# 测试计划

## 执行摘要
- **计划编号**：TEST_PLAN-REQ-APP-023
- **模块**：APP 发货单发货记录
- **需求**：REQ-APP-023
- **状态**：draft；本阶段仅输出测试计划。
- **输入**：需求说明书、需求变动、REQ-APP-023 分析文件、page.json、页面映射、.env、Schema 和原型入口。

基于 `app-plan-shipment-records` 的 `app023-records-empty`、`app023-records-populated` 证据，规划记录查询、累计数量、排序、位置明细、记录数边界、折叠规则、大数据量和返回条件。该页面与 APP-024 状态交叉，需按发货单上下文确认。

## 测试范围
### 范围内
- 空记录/有记录、累计发货、记录数量、计划号、本次数量、剩余未发和位置明细。
- 提交时间倒序、多位置、1-3 条/超过 3 条记录、默认折叠 3 条和展开全部需求。
- 大数据量加载及返回列表保留筛选、状态和搜索上下文。

### 范围外
- 创建、修改、删除和发货提交。
- 上孵计划记录独立规则，由 REQ-APP-024 承接。
- page.json 未确认的接口分页、错误码、字段和定位器。

## 测试策略
等价类/边界值覆盖记录数量和位置数量；状态转换覆盖列表到记录页、空态/有记录态、折叠/展开和返回；判定表组合记录数量、位置和来源；Pairwise 评估记录集、状态、位置、加载规模、来源页面和浏览器。自动化只规划 page.json 已采集证据，不生成脚本。
