# REQ-PC-048 上孵计划需求号关联与筛选

## 1. 分析结论

`REQ-PC-048` 是二期 PC 端“计划管理 / 上孵计划”需求，禅道模块 ID 为 `724`，优先级 `P0`。该功能属于一期已开发、二期无独立原型的既有功能延续。

以 `01_requirements/需求变动.md` 为优先依据，本需求确认以下业务能力和补充规则：

1. 上孵计划表格增加“孵化需求号”字段。
2. 上孵计划增加需求号筛选条件，采用模糊匹配，输入长度和格式均不限制。
3. “孵化需求号”列放在“养殖批次”列之前；空值显示 `-`；显示格式与孵化需求页面中的需求号一致，本需求不单独校验格式。
4. 上孵计划承接由孵化需求创建的计划，并保留需求号关联；同一需求号对应多个计划时不要求排序，分页沿用一期且不纳入本期测试，状态按计划状态筛选框过滤。
5. 从孵化需求行查看计划跳转上孵计划时，自动查询当前需求号，其他筛选条件不保留。
6. 需求号为空、重复或来源异常时显示 `-`；上孵计划仍可正常创建，但不关联孵化需求。本期暂时保留上孵计划新增和导入按钮，后期规划隐藏并使计划全部来源于孵化需求。

本次只分析需求、范围、规则、角色、页面/接口契约边界、风险、依赖、环境和数据前提；不生成测试用例、测试点、接口测试或自动化脚本。

- 需求号是孵化需求与上孵计划的关联上下文。

- 需求号筛选采用模糊匹配，输入长度和格式均不限制；命中时展示匹配范围内的关联计划，无匹配时展示无数据。

- 重置需求号筛选后恢复默认列表范围；默认排序等一期行为不在本期新增定义。
