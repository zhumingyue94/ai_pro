

# 遍历表格查找目标行和目标数据

## 场景1：没有横向滚动条
1. 在当前页逐行查看是否有目标数据：
    - 如果找到了目标数据则停止查找，这条数据就是目标行
    - 如果没有找到目标数据则进入第2步

2. 判断表格是否有纵向滚动条：
    - 如果有，则进入第3步
    - 如果没有，则直接进入第4步

3. 操作纵向滚动条，继续逐行查看目标数据是否存在：
    - 如果找到了目标数据则结束查找，这条数据就是目标行
    - 如果横向滚动条滑动到最后都没找到目标数据，进入第4步

4. 判断表格是否有分页：
    - 如果有分页，进入第5步
    - 如果没有分页，结束查找，判定为没有找到目标数据

5. 判定分页是否还有下一页：
    - 如果当前分页不是最后一页，分页切换到下一页，然后重新开始执行第1步
    - 如果当前分页已经是最后一页，结束查找，判定为没有找到目标数据




## 场景2：有横向滚动条

1. 在当前页逐行查看是否有目标数据：
    - 如果找到了目标数据则结束查找，这条数据就是目标行
    - 如果没有找到目标数据则进入第2步
2. 操作横向滚动条逐列查找目标数据，查看目标数据是否存在：
    - 找到了目标数据则结束查找，这条数据就是目标行
    - 没有，则直接进入第3步
3. 判断表格是否有纵向滚动条：
    - 如果有，则进入第4步
    - 如果没有，则直接进入第5步
4. 操作纵向滚动条和横向滚动条，继续逐行逐列查看目标数据是否存在：
    - 如果找到了目标数据则结束查找，这条数据就是目标行
    - 如果纵向滚动条滑动到最后都没找到目标数据，进入第5步
5. 判断表格是否有分页：
    - 如果有分页，进入第6步
    - 如果没有分页，结束查找，判定为没有找到目标数据
6. 判断分页是否还有下一页：
    - 如果当前分页不是最后一页，分页切换到下一页，然后重新开始执行第1步
    - 如果当前分页已经是最后一页，结束查找，判定为没有找到目标数据
