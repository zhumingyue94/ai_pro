## 4. 最新确认业务规则



以下规则来自 `需求变动.md` 的已登记确认项 `REQ-004-001` 至 `REQ-004-011`、`REQ-004-012` 和 `REQ-004-013`。



### 4.1 名称和描述



1. 分组名称为必填项。

2. 同一层级允许分组名称重复。

3. 分组名称和描述长度不限制，允许特殊字符；分组名称不得仅输入空格，按页面规则处理首尾空格，分组描述不要求处理空格；名称和描述均允许修改。

4. 分组描述为非必填项，可以为空。

5. 分组描述支持换行、空白和常见特殊字符。



### 4.2 状态和层级



1. 分组只有启用和停用两种状态。

2. 分组停用后不允许新设备归属。

3. 已有设备保留原分组。

4. 停用分组允许恢复启用。

5. 仅支持一级分组，不建立上下级关系。

6. 多级层级、每层数量、上下级关系和循环引用规则不适用。



### 4.3 设备关系和数量



1. 一台设备可以同时属于多个分组。

2. 设备加入或移出分组后立即生效。

3. 设备数量统计当前分组下全部未删除设备，包含停用设备。

4. 设备数量按设备唯一编号去重。

5. 设备数量受当前用户权限范围影响。

6. 每次进入页面或手动刷新时重新查询，不设置缓存。

7. 数据不一致时，以最新实际关联数据为准。



### 4.4 时间、排序和分页



1. 创建时间按当前用户时区显示。

2. 格式为 `YYYY-MM-DD HH:mm:ss`。

3. 时间筛选的起止时间均包含在查询范围内。

4. 分组列表默认按创建时间倒序排列。

5. 分页默认每页显示 10 条数据。



### 4.5 引用和删除



1. 分组存在关联设备时，仅禁止删除。

2. 存在关联设备时仍允许停用、改名和恢复。

3. 不需要先解绑设备。

4. 设备及历史记录保留。



### 4.6 页面规则验收



验证当前页面实际字段、筛选结果、设备数量、状态和操作反馈。若与已确认规则不一致，应记录为缺陷，而不是修改需求解释。



公共规则已经在最新确认中纳入本模块：分组名字搜索框采用模糊匹配且不区分大小写，首尾空格和连续空格不忽略；日期条件与分组名字同时生效；筛选后回第一页；无结果显示“暂无数据”；查询失败、超时、网络异常或权限不足显示失败提示且无重试入口；新增、编辑、删除等重复提交只处理一次，处理中禁用重复操作，完成后通过页面重新查询或手动刷新获取最新数据。验收证据记录实际筛选条件、页码、空状态、失败提示、按钮禁用和刷新后的列表结果，不进行接口测试。

## 7. 系统性测试设计



### 7.1 等价类



- 分组名称：合法、空、同名允许、仅空白、首尾/连续空格、特殊字符、名称可修改。

- 分组描述：空、合法、换行、空白、特殊字符、描述可修改。

- 日期筛选：无条件、单日、合法范围、包含边界、反向、非法、时区边界。

- 分组状态：启用、停用、未知。

- 设备关系：无设备、单个、多个、设备已在其他组、设备不可用。

- 权限：完整写入、只读、无权限、会话过期。



### 7.2 边界值



- 名称/描述：长度不限制；名称空、全空白、首尾/连续空格、Unicode、常见特殊字符和名称修改；描述空、换行、空白、特殊字符和描述修改。

- 日期：当天 `00:00:00`、`23:59:59`、单日、跨日、跨月/年、最大跨度、反向区间和时区边界。

- 设备数量：0、1、单页容量、容量+1、大规模统计、重复设备唯一编号去重。

- 分页：第 1/10/11 条、首末页、空列表、筛选后回第一页。

- 并发：同名新增、并发编辑、设备加入/移出与删除竞态。



### 7.3 判定表



| 条件 | 期望结果 | 状态 |

|---|---|---|

| 名称为空，新增/编辑 | 校验失败，不提交；编辑时保留输入 | 规则已确认，页面待验证 |

| 同一层级同名 | 按确认规则允许保存；同一层级重复名称不作为唯一性错误 | 规则已确认，页面待验证 |

| 分组停用，新设备归属 | 禁止新设备归属；已有设备保留原分组 | 规则已确认，页面待验证 |

| 存在关联设备，删除 | 禁止删除；停用、改名、恢复允许；设备及历史记录保留 | 规则已确认，页面待验证 |

| 设备加入/移出后查询或刷新 | 立即生效；数量按未删除设备唯一编号去重并受权限过滤 | 规则已确认，页面待验证 |

| 日期包含起止边界 | 起止时间均纳入，按当前用户时区解释 | 规则已确认，页面待验证 |

| 无权限/会话过期 | 显示权限/认证失败提示并停止业务验证 | 公共规则已确认，页面待验证 |

| 筛选后、重复提交或处理中 | 筛选回第一页；重复请求只处理一次；处理中禁用重复操作；完成后重新查询或手动刷新 | REQ-004-013已确认，页面待验证 |



### 7.4 状态迁移



```text

未认证 -> 登录页 -> 门户 -> device_group_default

默认列表 -> 查询中 -> 有结果/暂无数据/失败

分组草稿 -> 校验失败/保存成功/取消

启用 -> 停用 -> 恢复启用；停用禁止新设备归属，已有设备保留

无设备 -> 关联设备 -> 移出/设备删除；设备可同时属于多个分组

有关联设备 -> 删除阻止；停用、改名、恢复允许

无日期条件 -> 合法日期范围 -> 无结果/失败/非法范围

```



## 8. PICT 参数、取值与约束候选



```text

Auth: valid, expired, security_blocked

Permission: full_write, read_only, denied

Name: valid, empty, duplicate_allowed, whitespace_only, leading_trailing_spaces, consecutive_spaces, special_chars, editable

Description: empty, valid, multiline, whitespace, special_chars, editable

DateFilter: none, single_day, valid_range, inclusive_edges, reversed, invalid, timezone_boundary

DeviceRelation: none, one, many, in_other_group, unavailable

GroupState: enabled, disabled

Membership: single_group, multi_group

Action: query, add, edit, toggle, delete, move_device, reset, refresh

Result: success, validation_error, blocked_by_reference, membership_error, timeout, permission_error



IF [Permission] = read_only THEN [Action] IN {query, reset, refresh};

IF [Permission] = denied OR [Auth] != valid THEN [Result] = permission_error;

IF [Action] IN {add, edit} AND [Name] = empty THEN [Result] = validation_error;

IF [Action] = delete AND [DeviceRelation] != none THEN [Result] = blocked_by_reference;

IF [Action] = toggle AND [DeviceRelation] != none THEN [Result] = success;

IF [Action] = move_device AND [GroupState] = disabled THEN [Result] = membership_error;

IF [Action] = query AND [DateFilter] = reversed THEN [Result] = validation_error;

IF [Membership] = multi_group THEN [Result] IN {success, membership_error};

IF [Action] = refresh THEN [Result] = success;

IF [DateFilter] = inclusive_edges THEN [Result] IN {success, timeout};

```



PICT 仅用于候选场景设计；具体错误码、并发结果和接口语义需要后续契约确认。



## 9. 风险与控制



| 风险 | 等级 | 控制方向 |

|---|---|---|

| 关联设备时误删分组，导致设备归属和历史记录丢失 | 严重 | 只读核验删除阻止；写操作需授权、隔离数据和不可恢复边界 |

| 停用、恢复和多分组立即生效错误 | 高 | 核验状态迁移、已有设备保留、新设备禁止和多分组关系，不提交真实变更 |

| 设备数量未去重、遗漏停用设备或未按权限过滤 | 高 | 以设备唯一编号、未删除范围和当前权限作为核验条件 |

| 时区、包含边界、排序或分页错误 | 高 | 使用日期边界和当前用户时区设计只读验证 |

| 名称/描述字段规则 | 中 | 按最新确认处理字段校验；不写入真实业务值 |

| 页面证据泄露租户、分组、设备或内部地址 | 高 | 字段级脱敏，不保存业务原文、凭据、Cookie、Token 或未授权数据 |
