# 页面探索完成检查清单

> 本清单仅供人工复核，不是自动化门禁，不设置覆盖率阈值，不阻断页面探索或 CI 流程。

## 1. 页面级

- [ ] 路由、页面标题和菜单路径已确认。
- [ ] 实际内容宽度、高度及视口尺寸已记录。
- [ ] 页面滚动区域和横向溢出已检查。
- [ ] 默认状态截图保持原始比例，未使用 CSS 缩放。
- [ ] 默认状态 DOM 快照已脱敏保存。

## 2. 组件级

- [ ] 所有输入框已检查。
- [ ] 所有下拉、级联和日期控件已打开并记录实际选项或面板。
- [ ] 所有查询、重置、刷新和页面操作按钮已检查。
- [ ] 所有 Tab 已切换并记录内容变化。
- [ ] 所有展开/收起、更多配置和折叠面板已检查前后状态。
- [ ] 树节点、表头设置、抽屉和二级弹窗已检查。
- [ ] 表格列、排序、分页、横向滚动和行操作已检查。
- [ ] 空数据、加载、禁用或权限限制状态已记录或标记为 `blocked`、`partial` 或 `input_missing`。

## 3. 弹窗与表单

- [ ] 每个弹窗初始状态已记录。
- [ ] 展开状态已单独记录，新增字段没有只写在说明文字中。
- [ ] 字段名称、标签、角色、类型和定位器已记录。
- [ ] 必填、只读、禁用、默认值和选中状态已确认。
- [ ] `forms.field_element_ids` 覆盖所有已记录字段。
- [ ] 空提交校验已探索，无法执行时已明确标记。
- [ ] 确认、取消、关闭和遮罩行为已探索。

## 4. 交互与数据变更

- [ ] 每个会产生界面变化的控件都有前后状态或明确无变化结论。
- [ ] 新增、编辑、删除、启停和批量操作已记录责任边界。
- [ ] 未提交的操作已说明未改变业务数据。
- [ ] 已提交的测试数据有清理记录和结果。
- [ ] 无法提交或无法清理的操作未伪造成功结果。

## 5. 证据与脱敏

- [ ] 重要状态都有对应截图或明确说明无需截图。
- [ ] 重要状态都有对应 DOM 快照。
- [ ] `page.json` 已引用实际存在的截图、DOM 和日志。
- [ ] 浮层截图前已关闭上一个浮层，未出现重复遮挡。
- [ ] 截图未出现大面积空白或被裁切的操作区。
- [ ] DOM、截图、日志中没有账号、密码、Token、Cookie、认证状态或未授权业务隐私数据。
- [ ] 未被 `page.json` 引用的截图和 DOM 已清理。

## 6. 页面清单格式

- [ ] `elements`、`forms`、`tables` 和 `interactions` 与真实探索结果一致。
- [ ] 每个状态的证据路径和采集时间已记录。
- [ ] `page.json` 已通过 `.agents/references/page.schema.json` 格式校验。
- [ ] 格式校验结果不被解释为页面探索覆盖门禁结果。

## 7. 最终记录

- [ ] 浏览器会话已关闭。
- [ ] 探索日志记录了阻塞项、未执行项和数据变更边界。
- [ ] 已向交接人员说明仍未覆盖或无法确认的状态。
