## 3. 业务规则

### 3.1 指标和数据范围

- 分类数量来自产品分类页面的数据总数；分类今日新增为创建日期为今天的产品分类数量。
- 产品数量来自产品管理页面的数据总数；产品今日新增为创建日期为今天的产品数量。
- 设备数量来自设备管理页面的数据总数；设备今日新增为创建日期为今天的设备数量。
- 设备消息数来自设备管理页面逐台设备的“查看”弹窗中的设备消息页，为所有设备消息数汇总；设备消息今日新增为创建时间为今天的设备消息数量。
- 分类、产品和设备按唯一编号去重，消息按消息唯一编号去重。上述数据按当前租户及当前筛选范围统计，跨模块通过产品、设备和消息等业务唯一编号关联。

设备数量统计以产品分类作为环状图维度，鼠标悬停时显示该产品分类下绑定的设备数量。

### 3.2 时间范围和时间桶

“今日”按当前用户时区计算，开始和结束时间均包含。默认范围为前一天开始往前 7 个完整自然日；允许任意跨度、跨日、跨月、跨年和未来时间。支持天、周、月、季度、年五种间隔：周按周一至周日，季度按自然季度，边界按用户时区计算。缺失和被排除的异常数据显示为 `0`，异常不计入汇总。

### 3.3 设备和消息

设备状态统计来源于设备管理页面：在线设备为状态为在线的设备数量，离线设备为状态为离线的设备数量，未激活设备为状态为未激活的设备数量。连接建立为在线，连接断开立即离线，超过 10 分钟无心跳为离线，未激活为待激活，状态缺失为未知。断开优先于心跳阈值，重复设备按唯一编号去重，未知状态显示但不计入状态统计。

消息只统计总数，按消息唯一编号去重，延迟消息按实际到达时间，缺失显示 `0`，首页不分页。消息量统计在筛选时间范围内按消息标签区分：标签为上行的消息计入上行消息量，标签为下行的消息计入下行消息量。

### 3.4 刷新和异常

首次进入、筛选变化和手动刷新应重新获取最新数据；无自动刷新和缓存。刷新请求进行中按钮禁用，快速重复只执行一次。失败、超时或权限不足时清空数据并显示失败/权限提示；无数据显示 `0` 或空状态；部分缺失显示 `0`。指标卡片和图表仅展示汇总，不支持钻取、业务跳转和导出。

## 5. 测试边界设计

### 5.1 等价类

| 维度 | 等价类 |
|---|---|
| 租户 | 当前租户、跨租户、上下文缺失 |
| 日期范围 | 默认 7 天、同日、跨日、跨月、跨年、未来、非法范围 |
| 边界 | 开始包含、结束包含、范围外 |
| 时间间隔 | 天、周、月、季度、年 |
| 数据 | 正常、空、部分缺失、异常排除、重复编号 |
| 消息 | 唯一、重复编号、延迟、缺失 |
| 操作 | 首次进入、筛选变化、手动刷新、快速重复、无自动刷新 |
| 结果 | 成功、失败、超时、权限不足 |

### 5.2 边界值

重点覆盖：

- `00:00:00` 起始边界；
- `23:59:59` 结束边界；
- 周一和周日；
- 月末、季度末、年度末；
- 未来范围；
- 重复实体编号和重复消息编号；
- 快速重复刷新；
- 当前租户与跨租户上下文。

### 5.3 决策表

| 条件 | 期望规则 |
|---|---|
| 当前租户 + 筛选范围 + 重复 ID | 仅计数一次 |
| 起始/结束时间命中 | 均纳入统计 |
| 天/周/月/季度/年 | 按对应时间桶汇总 |
| 缺失或异常 | 缺失部分为 `0`，异常排除并按规则显示 `0` |
| 筛选变化 | 重新获取最新数据 |
| 卡片或图表点击 | 不钻取、不跳转、不导出 |

### 5.4 PICT 参数候选

参数：`Tenant`、`Range`、`Boundary`、`Interval`、`Data`、`Message`、`Action`、`Result`。

约束候选：

1. 跨租户或租户上下文缺失 → 权限拒绝或不展示数据；具体页面反馈需运行时确认。
2. 重复编号 → 操作成功但只计一次。
3. 空、部分缺失或异常排除 → 成功展示 `0` 或空状态。
4. 无自动刷新 → 不应产生自动刷新动作。

该模型仅用于测试设计，不生成、不执行测试数据。

## 7. 风险和依赖

### 风险

- 租户边界或去重错误导致越权或重复统计；
- 用户时区、起止包含和自然时间桶边界错误；
- 空数据、部分缺失和异常数据归零规则错误；
- 刷新重复请求、旧响应覆盖或缓存造成过期结果；
- canvas 图表缺少稳定定位导致自动化误判；
- 页面身份、历史路由和模块清单标题不一致导致验收对象错误。

### 依赖

首页没有上游页面依赖，但统计来源依赖：

- 产品分类；
- 产品管理；
- 设备管理；
- 消息/采集。

设备分组、插件管理、数据推送、数据监听、告警配置和告警记录属于关联链路，不代表跨模块一致性已经验证。
