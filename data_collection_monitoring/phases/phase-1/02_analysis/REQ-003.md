## 2. 已确认业务规则



### 2.1 产品名称、ProductKey 与分类



- 产品名称必填；长度、大小写、空白、特殊字符按系统默认限制；同租户唯一；编辑允许修改但仍需校验唯一性。

- `ProductKey` 由系统自动生成但允许修改；长度、字符、租户范围、唯一性和并发创建冲突按系统默认规则。

- 产品分类必填且只能选择启用分类。

- 分类停用后已有产品保留原分类；分类删除前需处理全部关联产品；分类改名后产品关联名称同步更新。



### 2.2 设备类型与媒体



支持直连设备、网关子设备、网关设备三种类型；产品建立后设备类型不可修改。产品图标和图片选填可为空，支持常见图片格式，上传数量、大小和尺寸按系统默认，允许替换。`REQ-003-013`进一步确认新产品分类下拉只显示启用分类，图片/图标只允许常见图片格式，上传失败需提示错误信息；上传控件行为以实际页面为准。



### 2.3 状态、物模型与关联



产品状态按“未发布 → 已发布 → 撤回 → 停用”流程转换，停用后允许再次发布，状态与当前版本关联，转换失败回退到转换前状态。物模型支持查看、编辑和按版本发布；发布前可编辑，发布后生成新版本；新版本需兼容已有设备；发布失败回滚且不影响在线设备当前运行。



产品存在设备、采集任务、推送配置或告警规则关联时仅禁止删除，仍允许编辑、停用、改分类和发布。最新 `REQ-003-015`明确本模块没有停用功能，允许撤回发布、编辑和再次发布；因此“停用”作为模块级状态规则保留为需与实际页面能力核对的契约，不臆造停用按钮。



### 2.4 导出和排序



导出字段与浏览器表格展示字段一致，按当前筛选结果导出；页面隐藏的敏感信息不得导出；浏览器直接下载，按系统默认数据量上限处理；失败显示提示，不单独记录下载，临时文件使用后自动清理。列表默认按创建时间倒序，筛选、分页和刷新后仍保持倒序。



### 2.5 页面验收范围



`REQ-003-011`沿用 `PUB-009` 页面级 UI/行为验收范围，不进行接口测试；在既有覆盖范围内验证实际字段、筛选结果、状态反馈、物模型入口和导出控件，不额外扩大。

## 5. 系统性边界分析



### 等价类与边界



- 名称：合法、空、同租户重复、其他租户同名、仅空白、特殊字符、系统默认边界。

- `ProductKey`：自动生成、手工修改、同租户重复、其他租户重复、仅空白、特殊字符、系统默认边界、并发冲突。

- 分类：启用、停用、缺失、改名、被引用。

- 设备类型：直连、网关子设备、网关设备、建立后不可修改。

- 媒体：无、合法图标、合法图片、非图片格式、同类重复、替换。

- 状态：未发布、已发布、撤回、停用、转换失败。

- 物模型：草稿可编辑、发布新版本、兼容、不兼容、发布失败回滚。

- 关联：无、设备、采集任务、推送配置、告警规则、多种关联。

- 导出：筛选、未筛选、隐藏敏感字段、超过上限、失败、清理待确认。

- 权限：完整、只读、拒绝、会话过期。



重点边界为名称/ProductKey空值和空白、系统默认限制、分类启停/改名/删除、三种设备类型建立前选择及建立后不可编辑、媒体格式和替换、状态迁移及失败回退、物模型兼容性与在线设备保护、关联删除阻止、分页首末页、筛选刷新后的创建时间倒序和导出脱敏。



### 判定表



| 条件 | 预期结果 |

|---|---|

| 名称为空，新增/编辑 | 校验失败，不提交；编辑保留输入 |

| 同租户名称或 ProductKey 重复 | 按唯一性规则阻止或提示，不提交重复主数据 |

| 分类停用，新增/编辑产品 | 停用分类不可选；已有产品保留原分类 |

| 产品已建立，修改设备类型 | 设备类型不可修改 |

| 存在设备/任务/推送/告警关联，删除 | 禁止删除；允许的其他操作需按确认规则验证 |

| 物模型不兼容或发布失败 | 阻止或回滚，不影响在线设备当前运行 |

| 当前筛选结果导出 | 字段与表格展示一致，不含隐藏敏感信息；失败提示并清理临时文件 |

| 筛选/分页/刷新 | 仍按创建时间倒序 |

| 无权限/会话过期 | 显示权限/认证失败提示并停止业务验证 |



### 状态迁移



```text

未认证 -> 登录页 -> 门户 -> product_management_default

产品草稿 -> 校验失败/保存成功/取消

未发布 -> 已发布 -> 撤回 -> 停用 -> 再发布

物模型草稿 -> 编辑 -> 发布新版本 -> 兼容通过/失败回滚

无关联 -> 关联资源 -> 删除阻止/其他允许

无筛选 -> 筛选结果 -> 分页/刷新 -> 创建时间倒序

导出准备 -> 浏览器下载/失败提示 -> 临时文件清理

```



## 6. PICT 参数与约束候选



```text

Auth: valid, expired, security_blocked

Permission: full, read_only, denied

Name: valid, empty, duplicate_same_tenant, special_chars, default_boundary

ProductKey: auto_generated, edited, duplicate, default_boundary, concurrency_conflict

Category: enabled, disabled, missing, renamed, referenced

DeviceType: direct, gateway_sub_device, gateway, immutable_after_creation

Media: none, valid, invalid_format, duplicate_type, replacement

State: unpublished, published, withdrawn, disabled, transition_failure

Model: draft, compatible_new_version, incompatible, publish_failure

Association: none, device, collection_task, push_config, alarm_rule, multiple

Action: query, add, view, edit, model, publish, withdraw, disable, delete, export, reset, refresh

Result: success, validation_error, blocked_by_reference, incompatible, rollback, permission_error, export_failure



IF [Permission] = read_only THEN [Action] IN {query, view, reset, refresh};

IF [Permission] = denied OR [Auth] != valid THEN [Result] = permission_error;

IF [Action] IN {add, edit} AND [Name] = empty THEN [Result] = validation_error;

IF [Action] = delete AND [Association] != none THEN [Result] = blocked_by_reference;

IF [Action] = model AND [Model] = incompatible THEN [Result] IN {incompatible, rollback};

IF [Action] = export AND [Permission] != full THEN [Result] = permission_error;

IF [Action] = edit AND [DeviceType] = immutable_after_creation THEN [Result] IN {success, validation_error};

IF [Action] = refresh THEN [Result] = success;

```



该模型仅用于边界分析，不生成或执行测试数据；具体错误码、并发、文件和接口结果待契约确认。
