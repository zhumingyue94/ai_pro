## 3. 已确认业务规则



### 3.1 分类字段



分类名称必填，只校验不能为空，不限制长度和字符；同租户内允许重名且不提示。描述非必填，可为空，支持换行、空白和常见特殊字符。排序字段为数字输入框，只允许正整数，不限最大值，允许重复；列表按排序字段升序，标题按系统默认规则。



### 3.2 状态与关联



状态包括启用、停用和删除。停用分类不可被新产品选择，但已有产品保留原分类。已被产品使用的分类允许改名，历史记录同步新名称；删除前需要处理全部关联产品，有关联时不得造成失联。分类与产品、设备分组及首页统计通过分类唯一编号关联，相关页面和统计在重新进入或手动刷新时更新。



### 3.3 时间、列表和数量



创建时间按当前用户时区保存和显示，格式为 `YYYY-MM-DD HH:mm:ss`。列表展示编号、名称、描述、状态、创建时间和操作六列；空字段显示 `-`；加载失败显示失败提示。产品数量规则为当前分类下全部未删除产品，包含停用产品、不包含已删除产品，进入页面或手动刷新时更新；但当前确认项同时明确本模块不要求产品数量列或对应列表接口字段，当前表格保持六列，因此数量规则需通过关联页面、统计或接口契约追踪，不能擅自添加列。



### 3.4 页面操作契约



新增默认启用；编辑回显；取消直接关闭并返回；保存中禁用提交且重复提交只处理一次；失败保留输入；并发冲突提示刷新重试；删除失败保留数据并说明原因。表头设置保存到当前用户，重新进入、切换页面或重新登录后保留。本轮只允许打开并取消表单或删除确认层，不执行提交、保存、停用或删除。

## 6. 系统性边界分析



### 等价类和边界值



- 名称：非空、空、仅空白、任意字符、同租户重名。

- 描述：空、多行、空白、常见特殊字符。

- 状态：启用、停用、删除。

- 排序：正整数、非法类型、空值、重复值。

- 关联：无关联、产品关联、设备分组关联、首页统计关联。

- 操作：查询、重置、刷新、新增、编辑、停用、删除。

- 结果：成功、校验失败、加载失败、保存失败、并发冲突、关联阻断、权限错误。



重点边界为名称空值和仅空白、排序正整数及非法值、时间格式及时区、分页首末页和空结果、停用后的新产品选择、有关联删除、保存中重复点击和并发冲突。



### 判定规则



| 条件 | 预期规则 |

|---|---|

| 名称为空或仅空白 | 校验失败 |

| 同租户名称重复 | 允许，不提示重名 |

| 分类停用 | 新产品不可选，已有产品保留原分类 |

| 分类存在关联且删除 | 阻止失联或按已确认关联处理 |

| 字段为空 | 列表显示 `-` |

| 列表加载失败 | 显示失败提示 |

| 保存中重复点击 | 提交按钮禁用且只处理一次 |

| 并发冲突 | 提示刷新重试，保留安全边界 |



### 状态转换



```text

未认证 -> 登录页 -> 门户 -> product_category_default

默认 -> 筛选 -> 结果 -> 重置/刷新

默认 -> 新增/编辑 -> 校验错误或取消

默认 -> 删除确认 -> 取消

启用 -> 停用 -> 既有关联保留/新产品选择阻断

```



### PICT 参数候选



参数为 `Auth`、`Permission`、`Name`、`Description`、`Status`、`Sort`、`Association`、`Action`、`Result`。只读权限只能执行查询、重置和刷新；新增/编辑且名称为空或仅空白时为校验失败；新增/编辑且同租户重名按确认规则允许；删除且存在关联时应进入关联阻断；排序为非法类型时校验失败。该模型仅用于需求边界分析，不生成或执行测试数据。
