## 4. 已确认业务规则

### 4.1 记录身份和时间

1. 记录编号由系统自动生成，必须唯一且不可修改；查询和排序使用系统生成的记录编号。
2. 每个告警事件由系统自动生成唯一事件标识；重复事件关联到同一事件。
3. 告警记录绑定事件触发时生效的规则版本。
4. 触发时间是监听条件满足并触发告警的时间；创建时间是系统生成告警记录的时间；数据来源时间是设备发送消息的时间。
5. 时间按当前用户时区显示，筛选也按当前用户时区执行。

### 4.2 历史和处理

1. 历史记录保存触发时的告警配置快照；配置后续停用、删除或修改不影响历史记录。
2. 是否处理仅有“是”和“否”两种状态；新记录为“否”，处理完成后为“是”。
3. 仅记录“否 → 是”的状态变化、操作人、操作时间和备注。
4. 不涉及确认、关闭、重开、转派和批量操作；处理记录不扩展为全局审计记录。
5. 当前页面不纳入阈值、实际值、单位、时间序列、位置、质量码、原始消息、通知状态和处理备注详情展示。

### 4.3 对象筛选和列表

1. 产品和设备支持级联筛选。
2. 失效、删除或无权限对象不能作为筛选条件选择。
3. 历史告警记录保留原对象信息。
4. 最新告警显示在列表最前，重复记录按事件标识关联。
5. 刷新后保持排序并避免重复记录。
6. 列表默认按创建时间倒序，筛选、分页和刷新后保持创建时间倒序。

### 4.4 留存、安全和权限

1. 告警记录、处理记录、历史快照和告警处理信息默认长期保存。
2. 有权限用户可以手动归档和删除；删除后不可恢复。
3. 详情按用户权限展示；设备标识、位置和测量值按业务需要展示。
4. 联系人、通知内容和触发消息中的敏感信息必须脱敏。
5. 按角色和租户范围验证查看、详情、处理、归档、删除及跨租户访问限制；接口细节不纳入测试。
6. 只验证页面按钮、确认框和结果提示，不实际执行不可恢复操作，不确认数据留存和清理。

## 6. 角色、依赖和风险

### 角色

- **告警记录查看者**：查看授权范围内的记录和脱敏详情；
- **告警处理者**：对授权记录执行“否 → 是”的处理并填写备注；
- **告警记录管理员**：按权限归档或删除记录，删除不可恢复；
- **只读用户**：查询和查看，不执行处理、归档或删除。

不得根据按钮、菜单或弹窗可见推断写权限，不得绕过角色、租户或不可恢复操作保护。

### 依赖

上游：`REQ-007` 数据监听、`REQ-009` 数据采集、`REQ-010` 告警配置、`REQ-003` 产品管理、`REQ-005` 设备管理及用户/权限/租户管理。下游：通知渠道与运维处置流程。

依赖只表示数据和责任边界，不代表接口、事件生成、历史快照或留存已经验证。

### 风险

- 处理、归档或删除会改变告警记录，删除不可恢复；只打开并取消，不提交副作用操作；
- 真实告警、触发消息、联系人或通知内容可能泄露；使用隔离/脱敏证据，不保存业务值；
- 跨租户或无权限对象可能可见；权限矩阵缺失时阻塞，不绕过权限；
- 重复事件、时区和历史快照语义无法由页面独立证明；记录为接口/契约待确认；
- 详情和处理反馈定位器不稳定可能导致误操作；缺失稳定定位器时不执行写操作。

## 7. 系统性测试设计

### 7.1 等价类

- 数据：有记录、无记录；
- 状态：已处理、未处理；
- 对象：有效、失效、删除、无权限；
- 时间：空、同日、跨日、非法范围、跨时区；
- 页面：默认筛选、展开筛选；
- 操作：查询、重置、查看、处理、归档、删除、刷新；
- 权限：完整、只读、拒绝、跨租户；
- 事件：新事件、重复事件；
- 结果：成功、无数据、权限失败、校验失败、超时/网络失败。

### 7.2 边界值候选

- 时间范围：空值、同一时刻、同日、开始晚于结束、跨日、跨月、跨年和时区边界；
- 分页：空、1 条、10 条、末页、无结果；
- 处理状态：`否 → 是`、重复提交和处理中再次操作；
- 处理备注：空、最小、最大和非法字符，具体边界待页面契约确认。

### 7.3 判定表

| 条件 | 期望结果 |
|---|---|
| 权限不足或跨租户 | 对受保护操作显示“没有操作权限”，不泄露受保护数据 |
| 未处理记录执行处理 | 允许进入处理流程；成功后状态变为“是”并记录操作人、时间和备注 |
| 已处理记录再次处理 | 按页面实际规则阻止或保持已处理；具体反馈待确认 |
| 处理重复提交或处理中再次操作 | 只生效一次，处理中禁止重复操作 |
| 重复事件刷新列表 | 按事件标识关联，刷新后不重复且保持排序 |
| 失效/删除/无权限对象筛选 | 不可选择；历史记录仍保留原对象信息 |
| 有权限删除 | 仅允许进入确认层；删除不可恢复，本阶段不确认 |
| 无删除权限 | 阻止操作并显示权限提示，本阶段不绕过 |

### 7.4 状态迁移

```text
未认证 -> 登录 -> 门户 -> 告警记录默认态
默认态 -> 展开筛选 -> 查询/重置
未处理 -> 处理表单 -> 处理成功为已处理，或失败后保持未处理
查看/处理弹窗 -> 取消关闭
记录 -> 归档/删除（仅契约观察，不执行）
```

## 8. PICT 参数与约束候选

```text
Permission: viewer, handler, administrator, denied
Tenant: same, other, missing
RecordState: unhandled, handled
EventIdentity: new_event, duplicate_event
Timezone: user_zone, daylight_boundary, cross_zone
ObjectAccess: valid, disabled, deleted, unauthorized
FilterMode: default, expanded
Action: query, reset, view, handle, archive, delete, refresh
Result: visible, filtered, no_data, permission_error, validation_error, saved, blocked, no_duplicate

IF [Tenant] = other OR [Permission] = denied THEN protected action results in permission_error;
IF [Action] = handle AND [RecordState] = handled THEN [Result] IN {visible, blocked};
IF [EventIdentity] = duplicate_event THEN [Result] = no_duplicate;
IF [ObjectAccess] IN {disabled, deleted, unauthorized} THEN protected filter selection is blocked;
IF [Action] = delete THEN [Permission] = administrator;
IF [FilterMode] = expanded THEN advanced filter elements are visible;
```

该模型用于 pairwise 页面/契约验证，不构成事件接口、告警生成或删除行为的执行授权。
