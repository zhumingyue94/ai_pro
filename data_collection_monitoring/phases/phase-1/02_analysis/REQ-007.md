## 3. 已确认业务规则



### 3.1 规则编号



规则编号由系统自动生成，创建后不可修改且必须唯一。发生重复或生成异常时提示并阻止保存。重复请求不重复生成编号。规则编号不是用户输入字段，唯一性和异常阻止属于系统责任边界。



### 3.2 规则名称



规则名称为必填项，同一租户内允许重复。最新补充确认规则名称限制非法字符但不限制字段长度。空白、首尾空白、连续空白以及修改规则仍按系统默认处理，具体提示和页面表现待确认。



### 3.3 规则状态



状态包括启用和停用。状态切换后立即生效。正在处理的事件按照触发时已经确定的规则状态执行，需要区分新事件处理和已经进入处理流程的状态快照。启用、停用、编辑和删除按角色权限及租户范围控制。



### 3.4 触发条件



支持三类触发来源：



- 设备属性，例如温度等属性值；

- 设备事件，例如故障等事件；

- 设备状态，例如在线或离线状态。



一个监听规则可以配置多个监听器，任一监听器满足即可触发。一个监听器可以配置多个条件，多个条件必须同时满足，才视为监听器满足。



```text

规则触发 = 任一监听器满足

监听器满足 = 该监听器全部条件满足

```



数据类型转换、表达式写法和阈值规则按系统默认规则处理，具体语法和边界暂不自行推断。



### 3.5 执行动作



支持：



- 推送；

- 触发告警；

- 取消告警。



多个动作按配置顺序执行。某个动作失败时记录失败，并继续执行后续动作。动作参数、条件失败、部分成功和重复执行规则按系统默认规则处理，失败记录位置和页面反馈待确认。



### 3.6 创建时间和排序



创建时间按当前用户时区显示，格式为：



```text

YYYY-MM-DD HH:mm:ss

```



默认、筛选、分页、刷新后均按创建时间倒序，最新创建规则在前。服务端排序字段、分页并列值处理和页面稳定排序证据仍待补充。



### 3.7 运行引用



推送目标或告警配置停用后，不允许被新的监听规则选择；已经使用该配置的监听规则不受影响，继续使用原配置进行推送。推送目标或告警配置被监听规则使用时不允许删除。



```text

停用依赖 -> 新规则不可选

已有引用 -> 继续使用原配置

被规则引用 -> 依赖不可删除

```



不能将该规则简化为“依赖停用后所有已有规则失效”。



### 3.8 触发处理



设备每次上报事件都执行一次推送或告警动作。重复事件不去重，不设置节流或时间窗口，同一事件每次上报都可以触发动作。动作失败后只记录失败结果，不自动重试。

## 7. 风险



1. 监听器 OR/AND 逻辑错误导致漏触发或误触发。

2. 动作失败后未继续、自动重试或重复副作用。

3. 停用或删除依赖破坏已有监听规则。

4. 状态切换未立即生效，或处理中事件使用错误状态。

5. 规则编号重复、可编辑或重复请求重复生成。

6. 用户时区、时间格式或筛选/分页/刷新排序错误。

7. 租户隔离或角色权限缺失导致规则和依赖跨租户暴露。

8. 页面库存缺失导致自动化误用其他模块定位器。



## 8. 系统性测试设计



### 8.1 等价类和边界候选



- 规则编号：系统生成唯一、冲突/生成异常、重复请求幂等、编辑尝试；

- 规则名称：必填、空值、空白、非法字符、同租户重复、不限长度；

- 状态：启用、停用、立即切换、处理中事件状态快照；

- 触发来源：设备属性、设备事件、设备状态；

- 监听器逻辑：单监听器全部满足、部分不满足、多监听器一个满足、全部不满足；

- 动作：推送、触发告警、取消告警、多动作顺序、中间失败、全部失败；

- 依赖：启用可选、停用不可新选、已有引用保留、被引用不可删除；

- 事件：唯一事件、重复事件、无节流窗口、失败不重试；

- 时间：用户时区、秒级格式、默认/筛选/分页/刷新倒序；

- 权限：授权、未授权、跨租户。



### 8.2 判定表



| 条件 | 期望结果 |

|---|---|

| 多监听器中任一监听器全部条件满足 | 触发动作 |

| 单监听器存在一个条件不满足 | 该监听器不满足 |

| 动作按顺序执行且中间动作失败 | 记录失败并继续后续动作，不自动重试 |

| 依赖已停用且新建规则选择 | 不允许选择 |

| 依赖已被现有规则引用 | 现有规则继续使用原配置，依赖不允许删除 |

| 同一事件重复上报 | 每次上报均执行，不去重、不节流、不使用时间窗口 |

| 默认、筛选、分页、刷新 | 均按创建时间倒序 |

| 事件已进入处理后规则状态变化 | 已处理事件沿用触发时确定的规则状态 |



### 8.3 状态迁移



```text

不存在 -> 已创建

已创建 -> 启用

启用 -> 停用

停用 -> 启用

启用/停用 -> 编辑

被引用依赖 -> 停用请求 -> 禁止新规则选择但已有引用继续

被引用依赖 -> 删除请求 -> 拒绝

设备事件上报 -> 规则状态快照 -> 监听器匹配 -> 动作顺序执行 -> 成功/部分失败

重复事件上报 -> 重复执行

动作失败 -> 失败记录 -> 不重试

列表初始 -> 筛选/分页/刷新 -> 创建时间倒序

```
