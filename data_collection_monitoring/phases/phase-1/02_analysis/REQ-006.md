## 3. 最新业务规则



### 3.1 插件名称



插件名称由系统生成的默认插件名称和用户填写的端口拼接生成，格式为：



```text

系统生成的默认插件名称-插件端口

```



默认插件名称由系统自动生成且不允许修改，最终名称随端口号确定。页面库存中的 `plugin_management_add_name` 为必填、可编辑、`readonly=false`，构成需求与页面实现冲突。需求规则已确认，页面是否符合仍待只读复核，不通过提交新建验证。



### 3.2 类型与协议



新增插件仅选择插件类型，不单独选择协议；插件类型本身代表协议。确认类型为：



- `emqx`

- `mqtt`

- `http`



协议版本和设备类型兼容关系按所选类型的系统规则处理。页面库存目前只观察到 `MQTT`、`HTTP`，未观察到 `emqx`，不能因此判定需求类型不存在。



### 3.3 端口



最新确认要求：



- 端口必须是合法数字端口；

- 禁止使用保留端口；

- 创建时检查端口冲突；

- 同协议和跨协议均不允许重复；

- 具体范围、租户隔离方式和错误提示按实际页面记录。



这覆盖并细化了旧回答中“同协议不可重复、不同协议可复用”的表述，分析以最新确认回答为准。



### 3.4 编号



插件编号由系统自动生成，创建后不可修改，全局唯一；发生重复时系统拒绝创建。插件编号不应作为用户输入字段。



### 3.5 状态与生命周期



插件支持创建、启动、停止和删除，状态包括：



- 已创建；

- 运行中；

- 已停止。



停止后可以再次启动，列表按创建时间倒序。需求还要求记录重启、故障恢复和异步失败的页面按钮、状态变化及反馈，但不补充接口契约。独立关联规则为：运行中不可删除但允许停用，停用后允许删除。



候选状态路径：



```text

已创建 -> 运行中 -> 已停止 -> 运行中

运行中 -> 停用 -> 删除允许

运行中 -> 删除请求 -> 拒绝

```



### 3.6 设备数



设备数统计当前插件关联的全部未删除设备：



- 包含停用设备；

- 按设备唯一编号去重；

- 删除设备排除；

- 进入页面或手动刷新时重新查询；

- 不设置缓存；

- 数据不一致时以重新查询得到的最新实际关联数据为准。



`page.json` 只记录 `device_count` 列，尚未形成去重、删除排除、停用包含和刷新重查的页面证据。



### 3.7 配置和关联



插件创建后不支持修改配置，页面不提供编辑功能，不涉及配置升级、灰度、回滚及设备类型兼容规则。运行中插件禁止删除但允许停用，停用后允许删除。其他迁移和替换规则按实际页面功能记录，不自行扩展。



### 3.8 安全字段



地址按业务需要展示。证书、密钥和敏感配置在表单、运行详情、日志和错误提示中均必须脱敏，不允许明文输出；删除或替换敏感信息后必须清理旧值。分析产物、截图、日志、DOM、报告和下载文件不得记录真实敏感值。



### 3.9 排序、筛选和表头



默认及筛选、分页、刷新后均按创建时间倒序。分页、筛选、刷新、排序和表头设置的定位方式沿用 `PUB-015`，但具体分页字段、稳定定位器、并列值处理和表头设置持久化范围仍待页面记录。

## 5. 角色、依赖和风险



角色候选：



- **插件查看人员**：查看授权范围内插件、状态、设备数和详情。

- **插件管理员**：按权限创建、启动、停止、停用和删除插件。

- **设备/产品管理员**：维护插件关联设备和产品依赖。

- **平台运维/审计人员**：维护运行状态、安全保护和异常处置。



不能从页面按钮可见性推断写权限。需按角色验证查看、创建、启动、停止和删除等页面权限；插件管理列表不需要针对不同租户进行管理，不将租户差异作为列表管理、筛选或隔离条件；接口细节不纳入测试。



依赖模块为产品管理和设备管理，下游涉及设备消息、采集/连接链路、运行监控、告警和审计。模块拆分依赖仅为范围线索，不代表接口事实。



主要风险：



1. 证书、密钥或敏感配置在表单、详情、日志或错误提示中明文泄露。

2. 运行中插件被删除或停用后状态不一致。

3. 端口重复、保留端口和范围规则实现错误。

4. 名称、编号或状态选项与最新确认不一致。

5. 设备数未去重、未排除删除设备、未包含停用设备或未按刷新重查。

6. 筛选、分页、刷新后未保持创建时间倒序。



## 6. 系统性测试设计



### 等价类



- 名称：系统生成、端口派生、编辑尝试。

- 类型：`emqx`、`mqtt`、`http`、不支持类型。

- 端口：合法唯一、同协议重复、跨协议重复、保留端口、越界、非法格式。

- 生命周期：已创建、运行中、已停止、停止后启动、重启、故障恢复、异步失败。

- 设备数：活动设备包含、停用设备包含、删除设备排除、重复编号去重、进入/刷新重查。

- 安全字段：地址可展示、证书脱敏、密钥脱敏、敏感配置脱敏、旧值清理、明文禁止。

- 权限：已授权、未授权；租户差异不作为插件管理列表的管理条件。



### 判定表



| 条件 | 期望结果 |

|---|---|

| 同协议或跨协议端口重复 | 创建拒绝并按页面实际反馈展示原因 |

| 合法数字、非保留且唯一端口 | 允许进入创建流程，最终结果按页面规则记录 |

| 运行中插件删除/停用 | 删除拒绝，停用允许 |

| 已停用插件删除 | 允许进入删除流程，页面反馈按实际记录 |

| 设备删除、停用、编号重复 | 删除设备排除，停用设备包含，重复编号只计一次 |

| 敏感字段位于表单/详情/日志/错误提示 | 全部脱敏，禁止明文；删除/替换后旧值清理 |

| 默认、筛选、分页、刷新 | 均按创建时间倒序 |

| 未授权 | 不允许超出角色页面权限，并显示页面实际反馈 |

| 不同租户 | 插件管理列表不按租户分别管理、筛选或隔离 |



### 状态迁移



```text

不存在 -> 已创建 -> 运行中 -> 已停止 -> 运行中

运行中 -> 停用 -> 删除允许

运行中 -> 删除请求 -> 拒绝

关联变化 -> 进入页面/手动刷新 -> 重新查询 -> 设备数更新

敏感值存在 -> 删除/替换 -> 旧值清理

```



## 7. PICT 参数/约束候选



```text

Type: emqx, mqtt, http, unsupported

PortRelation: unique, same_protocol_duplicate, cross_protocol_duplicate, reserved, out_of_range, invalid

Lifecycle: created, running, stopped, restart, fault_recovery

DeviceSet: active, disabled, deleted, duplicate_id, refreshed

SecurityLocation: form, detail, log, error

Ordering: default, filtered, paged, refreshed

Permission: authorized, unauthorized, cross_tenant



IF [PortRelation] IN {same_protocol_duplicate, cross_protocol_duplicate, reserved, out_of_range, invalid} THEN [Lifecycle] <> created;

IF [SecurityLocation] IN {form, detail, log, error} THEN [Permission] = authorized;

IF [Permission] IN {unauthorized, cross_tenant} THEN [Lifecycle] <> restart;

```



以上为候选参数、取值和约束，不代表已执行组合测试；创建、启动、停止、删除和敏感配置提交均不执行。
