# 测试计划



## 执行摘要



- **计划编号**：`TEST_PLAN-REQ-001`

- **模块**：首页

- **需求**：`REQ-001`

- **状态**：draft；本阶段仅输出测试计划。

- **目标**：规划首页可达性、日期范围、时间间隔、指标与筛选结果的限定范围只读验证。

- **关键边界**：`page.json` 的 home 页面采集状态为 `partial`；统计区域、图表、刷新、提示、筛选结果和加载状态未登记稳定独立定位器，未确认事实不得编写为页面事实。



## 测试范围



### 范围内



- 运行时确认首页路由、标题、菜单路径及可达性；以 `page.json` 的 home 页面记录为参考。

- 只读检查 `home_default`、`home_date_range`、`home_menu_expanded`，以及开始日期、结束日期、时间间隔和已采集日期快捷项。

- 规划默认范围、起止包含、同日/跨日/跨月/跨年/未来范围、无最大跨度和用户时区边界验证。

- 规划天、周、月、季度、年时间桶，以及缺失、空数据、异常排除、唯一编号去重和消息编号去重的结果核对。

- 规划当前租户与筛选范围、首次进入、筛选变化和手动刷新后的只读结果观察。

- 规划分类、产品、设备及设备消息指标的来源和"今日新增"口径：分别核对产品分类、产品管理、设备管理页面及设备消息页的数据总数、创建日期/创建时间和消息唯一编号去重。

- 规划设备数量统计环状图按产品分类维度展示绑定设备数量、悬停信息，以及设备管理页面在线、离线、未激活状态统计。

- 规划筛选时间范围内按消息标签核对上行和下行消息量；无消息或部分数据缺失时核对 `0` 或空状态展示。

- 规划指标卡片与图表仅汇总展示、不钻取、不业务跳转、不导出的边界观察；未确认定位器不得自动化。

- 规划当前账号实际首页访问范围、数据安全和跨需求来源链路验证准备。



### 范围外



- 设备状态实时性、刷新失败清空、权限提示路径和接口契约的实际验收。

- 新增、编辑、删除、保存、提交、导入、导出、下载、造数、接口写入、业务钻取和业务跳转。

- 性能 SLA、压力、接口性能、缓存实现和未批准的数据修改验证。

- `page.json` 未出现的按钮、字段、菜单、弹窗、状态、定位器、错误码或 CSS/data-testid。

- 测试点、测试用例、CSV、禅道数据、注册表和 UI 自动化脚本。



## 测试策略



- 采用黑盒、只读、风险优先策略；以 `REQ-001-001` 至 `REQ-001-017`、`REQ-001.yaml` 和 `page.json` 已采集事实为基线。`partial` 状态下不可观察内容记录为待确认或无法验证，不据此判失败。

- 使用等价类划分覆盖租户、日期范围、数据状态、消息状态和操作动作；使用边界值覆盖前一天起点、完整自然日、起止时刻、周/月/季度/年度边界、未来时间和重复刷新边界。

- 使用判定表评估租户与筛选范围、起止包含、时间桶、缺失/异常归零、唯一编号去重、消息到达时间、筛选/刷新取最新数据及卡片/图表无钻取跳转导出。

- 使用状态转换覆盖未认证到门户再到 `home_default`、日期面板/菜单展开、筛选或刷新到更新/失败待确认；不虚构未采集状态。

- Pairwise/2-way 评估 `Tenant`、`Range`、`Boundary`、`Interval`、`Data`、`Message`、`Action`、`Result` 组合；执行前确认参数值、约束和数据可观察性。

- Playwright Python/pytest-playwright 仅规划自动化范围：复用公共登录和门户导航，优先 role/name、accessible label、已确认 data-testid 或 page.json element mapping；当前仅已采集日期和时间间隔控件可作为候选，统计区域等需运行时确认。

- Web 执行采用导航后等待可观察状态、操作前后状态比对和证据采集；不使用未确认定位器，不执行写操作，不保存凭据、Token、Cookie 或真实敏感业务值。
