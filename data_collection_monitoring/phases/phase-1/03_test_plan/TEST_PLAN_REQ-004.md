- Playwright Python/pytest-playwright 仅规划自动化范围：复用 `login_page.py` 和 `portal_navigation.py`，优先 role/name、accessible label、确认的 data-testid、`page.json` 元素语义映射、表格行上下文和可见文本；CSS 只作为最后手段。仅自动化导航、默认列表、筛选/分页/表格/表头/日期面板只读观察和安全取消；编辑、删除确认、状态、设备关联、失败提示因证据不完整保持人工或 blocked。
- Web 执行采用导航后等待可观察状态、操作前后页面比对、脱敏截图/DOM/日志证据；禁止固定等待、未确认定位器、保存/删除/停用/恢复/设备加入移出、接口写入和绕过权限/安全验证。
