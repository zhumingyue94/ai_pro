# 通用 UI 自动化执行规则

本文件只规定公共执行边界；业务页面、角色、自然唯一键、状态链和业务断言由项目覆盖层提供。

- 执行前读取本地用例、评审门禁快照（`gate_passed`、`gate_reasons`）、数据角色和断言契约；评审门禁失败不阻断本地执行。
- 页面操作必须等待目标控件、弹窗、遮罩、表格和数据稳定。
- 每条用例独立记录 readiness、动作、断言、截图、结果分类和清理状态。
- 失败先分类并保留证据，不自动把脚本错误或阻塞误报为产品 Bug。
- 业务写操作必须遵循项目数据契约、结果回读和清理授权。
- 本自动化阶段只创建、验证和保存可独立启动的用例脚本；不得创建、恢复、要求或自动执行任何 `run_*.py`、批量 runner 或替代调度入口。
- 在用户明确手动创建批量入口前，不执行批量调度；批量执行文件由用户后续自行创建和启动。
